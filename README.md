# Мандат

**Единое окно полномочий для бизнес-клиентов банка.** «Мандат» отвечает на вопрос, который сегодня решают вручную и часто в офисе: *вправе ли этот человек провести эту операцию от имени этой компании на эту дату?*

Ответ всегда один из четырёх — **ПОДТВЕРЖДЕНО**, **ОПРОВЕРГНУТО**, **НА РАЗБОР**, **НЕДОСТАТОЧНО ДАННЫХ** — и к каждому прилагаются доказательства: XPath поля МЧД, запись ЕГРЮЛ с ГРН, фрагмент устава, применённая норма. Если данных не хватает, система не говорит «да», а называет недостающий документ и подразделение, которое ведёт кейс.

Проект делается для трека ВТБ «Финтех без границ» (Академия Финтеха 2026). Стадия — вертикальный срез на синтетических данных; что работает и что пока заглушка, честно перечислено ниже. Нормы, мировой уровень и конкуренты сверены 12.10.2026: `docs/REGULATORY.md`, `docs/SOTA.md`, `docs/COMPETITORS.md`.

## Как это работает

```
документы клиента          граф полномочий на дату            вердикт и доказательства
МЧД (XML, формат 003)  ─┐   ЕГРЮЛ: руководитель (ГРН)          32 правила со ссылкой на норму
бумажная доверенность   ├─► → МЧД → передоверие → представитель ─► свёртка без ложного «да»
устав, протоколы        │   сроки, отмена, объём, устав           следующий шаг и маршрут
ЕГРЮЛ, реестр МЧД      ─┘   классификатор полномочий на дату      журнал с деревом Меркла
                                                                  удостоверение со статусом
события: смена руководителя, отмена МЧД, смена реквизитов ──► перепроверка прав, отзыв удостоверений
```

- **Правила решают, модель советует.** Языковая модель только предлагает факт из устава с дословной цитатой; без цитаты факт не засчитывается, а вердикт она не меняет (ADR-001). Автоматический вердикт можно оспорить у человека — в логике Кодекса этики в сфере ИИ, к которому ВТБ присоединился в августе 2026 года.
- **Тишина — не успех.** Обязательная группа проверок считается выполненной, только если в ней есть подтверждение и нет «не проверено». Недоступный реестр даёт «недостаточно данных», а не «действует».
- **Нормы 2026 года.** Смена руководителя доверенность не прекращает (п. 1 ст. 188 ГК РФ): давняя смена — сигнал, свежая — повод для разбора. Отмена основной МЧД обрывает передоверие (п. 3 ст. 188). Без срока МЧД действует год (ст. 186). Реквизиты — по Приказу Минцифры № 1001. Под формы Банка России по 315-ФЗ есть слот.
- **Передоверие не расширяет полномочия** — проверено на всех 384 двухзвенных цепочках и независимой реализацией на Cedar (ADR-006).
- **Права рекомендуются, а не выдаются.** На пилоте режим теневой. Удостоверение о проверке живёт со статусом: отмена МЧД его отзывает, признаки захвата — приостанавливают (W3C Bitstring Status List, ADR-007).
- **Всё в контуре банка.** Ядро работает без сети; модель подключается только к хостам из белого списка, ПДн псевдонимизируются перед отправкой.

## Быстрый старт

Нужен Python 3.11+.

```bash
pip install -e ".[dev,api]"                    # для проверки на Cedar: ".[dev,api,cedar]"
mandat demo                                    # 12 демо-кейсов → var/demo: отчёты, журнал, удостоверения, списки статусов
mandat verify examples/cases/10_old_director_poa --html var/10.html
mandat monitor examples/events/poa_revoked.json --status-dir var/demo/status   # отмена основной МЧД
mandat monitor examples/events/takeover.json --status-dir var/demo/status      # признаки захвата
mandat attest-verify var/demo/attestations/01_ok.json \
  --public-key "$(cat var/demo/public_key.txt)" --status-dir var/demo/status   # подпись и статус
mandat journal-proof var/demo/journal.jsonl --seq 3                            # доказательство включения
mandat eval --per-defect 6                     # синтетический корпус: 34 вида, риск и покрытие
python -m pytest                               # тесты
MANDAT_API_TOKEN=secret mandat serve           # HTTP API, документация на /docs
```

Без установки пакета: `./run-demo.sh` (Linux/macOS) или `run-demo.ps1` (Windows). В Docker: `docker compose up --build`. Проверка окружения: `make doctor`.

## Что работает и что пока заглушка

| Часть | Статус |
|---|---|
| Разбор МЧД формата 003 по файлу соответствия полей, защита от XML-бомб, реестр форматов | работает; часть путей ждёт сверки с официальной XSD — `docs/FORMAT_NOTES.md` |
| Граф полномочий: руководитель → МЧД → передоверие, сроки, однократное передоверие, сужение, каскад отмены, утрата полномочий, совместные полномочия | работает |
| 32 правила со ссылкой на норму, параметры банка, профили `demo` и `strict` | работает; все правила в статусе `draft` до проверки юристом |
| Отчёт JSON/HTML с плашкой «Режим стенда», следующий шаг, маршрут, рекомендация роли | работает |
| Журнал с хеш-цепочкой, HMAC и деревом Меркла; удостоверение Ed25519 со списками статусов W3C | работает |
| Мониторинг событий: захват, отмена МЧД с каскадом, смена руководителя | работает на событиях из файла |
| Независимая проверка ядра передоверия на Cedar | работает в тестах (extra `cedar`) |
| Псевдонимизация ПДн (ИНН, СНИЛС, паспорт, телефон, почта) | работает |
| Извлечение ограничений устава | шаблоны; модель — опционально, через шлюз цитат |
| Реестр МЧД, ЕГРЮЛ | заглушки с данными из кейса; в пилоте — адаптеры банка |
| Проверка КЭП по ГОСТ | порт есть, статус всегда «не проверено»; в пилоте — СКЗИ банка |
| Коды полномочий | синтетические `SYN-…` со статусом сверки; импорт из выгрузки ЕСНСИ готов |

Цифры проекта собирает `python scripts/build_evidence.py` в `evidence.json`; каждое утверждение для жюри должно быть в `CLAIMS_REGISTRY.md`.

## Карта репозитория

```
src/mandat/
  domain/        модель, идентификаторы, граф полномочий, свёртка вердикта
  intake/        безопасный XML, МЧД, реестр форматов, ЕГРЮЛ, устав, загрузка кейса
  rules/         пакет правил, их реализация, классификатор, экспорт в Cedar
  services/      проверка кейса, следующий шаг, рекомендация роли, мониторинг
  audit/         журнал, дерево Меркла, удостоверения, списки статусов
  advisory/      модель-советник: шлюз цитат, клиент OpenAI-совместимого API, пояснение по фактам
  privacy/       поиск и псевдонимизация ПДн
  review/        разбор исключений человеком, апелляция
  report/        HTML-карточка кейса
  eval/          синтетический корпус и метрики
  api/, cli.py   HTTP API и командная строка
  data/          rules.json, operations.json, authority_classifier.json, emchd_003_mapping.json
policies/cedar/  политики Cedar (генерируются: scripts/export_cedar.py)
examples/        демо-кейсы и события (генерируются: `mandat examples`)
docs/            архитектура, нормы, мировой уровень, литература, конкуренты, экономика, ADR, discovery
scripts/         evidence.json, документ правил, Cedar, импорт классификатора, калькулятор эффекта
submission/      структура сдачи по спринтам
```
