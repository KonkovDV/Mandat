# Кодекс поведения

В «Мандате» действует [Contributor Covenant 2.1](https://www.contributor-covenant.org/ru/version/2/1/code_of_conduct/) — кодекс поведения, принятый во многих открытых проектах. Полный текст на русском — по ссылке, здесь главное.

## Чего ждём

- Уважения к участникам и к чужому опыту.
- Критики по существу: о коде, норме или документе, а не о человеке.
- Готовности признать ошибку и исправить её.

## Что недопустимо

- Оскорбления, травля и переход на личности.
- Домогательства в любой форме.
- Публикация чужих персональных данных без согласия. Здесь это касается и документов клиентов: реальные МЧД, выписки ЕГРЮЛ и уставы в issue и pull request не прикладываются.

## Куда сообщить

Приватно владельцу репозитория [@KonkovDV](https://github.com/KonkovDV). Форма GitHub «Report a vulnerability» на 27.10.2026 постороннему недоступна: private vulnerability reporting выключен ([как сообщить](SECURITY.md#нашли-уязвимость)). Нарушение правил самого GitHub — через «Report content». Жалоба рассматривается конфиденциально, её автор не раскрывается.

Меры — по лестнице из Contributor Covenant: исправление, предупреждение, временный и постоянный запрет на участие.
