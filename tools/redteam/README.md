# Фазз движка

Мутации «зелёных» сценариев ищут ложное «подтверждено». Постоянный тест требует, чтобы таких не было ни одного.

- `common.py` и `fuzz_mutations.py` — около 350 видов мутаций, 3 зерна, профили `demo` и `strict`.
- `tests/test_redteam_fuzz.py` — постоянный тест. Он берёт базу с отметкой об уставе: без неё базовые сценарии не дают «подтверждено», и проверять нечего.
- Поправленные ожидания стенда и открытые вопросы перечислены в самом тесте (`EXPECTATION_FIXES`, `OPEN_QUESTIONS`).

Ручной запуск с исходными ожиданиями: `python fuzz_mutations.py` из этого каталога.
