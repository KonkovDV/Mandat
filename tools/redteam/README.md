# Фазз движка

`common.py` и `fuzz_mutations.py` — мутации зелёных сценариев (около 350 видов, 3 зерна, профили `demo` и `strict`).
Постоянный тест: `tests/test_redteam_fuzz.py`. Он берёт базу с отметкой об уставе, иначе базовые сценарии
не дают «подтверждено» и фазз ничего не проверяет, и требует ноль ложных «подтверждено».

Ожидания стенда, которые тест исправляет, и открытые вопросы перечислены в самом тесте
(`EXPECTATION_FIXES`, `OPEN_QUESTIONS`).

Ручной запуск с исходными ожиданиями стенда: `python fuzz_mutations.py` из этого каталога.
