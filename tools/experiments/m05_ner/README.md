# M-05: ФИО вне данных кейса — офлайн-NER или словарь (#65)

Эксперимент, а не часть пакета: зависимостей в `pyproject.toml` не добавляет. Вопрос: чем ловить ФИО, которых
нет в данных кейса, перед отправкой текста в модель. Принцип — при сомнении маскировать.

## Как повторить

```bash
python tools/experiments/m05_ner/fetch.py            # Wikidata и 14-ФЗ в ~/.cache/mandat-m05
python -m venv .venv-m05 && .venv-m05/bin/pip install natasha pymorphy3
.venv-m05/bin/python tools/experiments/m05_ner/build_set.py                    # набор A, seed 20261016
.venv-m05/bin/python tools/experiments/m05_ner/run.py --natasha
.venv-m05/bin/python tools/experiments/m05_ner/build_set.py 777 names_set_b.json  # набор B
NAMES_SET=names_set_b.json .venv-m05/bin/python tools/experiments/m05_ner/run.py --natasha
```

Данные в репозиторий не входят: в них настоящие ФИО.

## Размеченный набор

- **Люди:** пары «фамилия, имя» людей с гражданством России 1960–1995 г. р. из Wikidata (CC0), 6000 записей.
  Женская фамилия образуется по правилу (-ов → -ова, -ский → -ская). Отчество синтетическое: от одного из 14
  частых мужских имён. Падеж — через pymorphy3 (только для построения набора).
- **Шаблоны:** 9 предложений из устава, доверенности и заявки: именительный, родительный, дательный,
  творительный и предложный падежи, «Фамилия И.О.», «И. О. Фамилия», «Имя Отчество Фамилия», одна фамилия,
  «Имя Отчество».
- **Разбиение:** словарь фамилий (7536 фамилий Wikidata с кириллической записью) делится пополам по хешу.
  Словарный метод получает только половину; «seen» — люди с фамилией из неё, «unseen» — с остальными
  фамилиями. Это проверка на фамилиях, которых нет в словаре.
- **Объём:** в каждом наборе 540 предложений (270 seen + 270 unseen), 1200 размеченных слов ФИО.
  Наборы A и B — разные выборки из тех же 6000 записей и могут частично пересекаться.
- **Ложные срабатывания:** главы I–IV 14-ФЗ «Об обществах с ограниченной ответственностью» (Викитека) и
  40 синтетических фраз устава и доверенности (`fp_extra.txt`): органы общества, названия организаций и
  банков, города, адреса. ФИО в них нет; считаются слова с заглавной буквы, попавшие под маску (976 слов).
- **Шум разметки:** pymorphy3 склоняет не всё (несклоняемые и редкие фамилии остаются в именительном).

Полнота: «слова» — доля слов ФИО под маской; «люди» — доля предложений, где замаскированы все части ФИО.
Инициалы не считаются.

## Результат

| Метод | seen: слова / люди | unseen: слова / люди | Ложные маски, 976 слов | Время на набор |
|---|---|---|---|---|
| Словарь (Wikidata, правила суффиксов) | A 91,5 / 85,2 %; B 92,3 / 84,8 % | A 79,3 / 66,7 %; B 79,2 / 63,7 % | 11 (1,1 %) | 0,03 с |
| Natasha / Slovnet NER | A 97,0 / 94,1 %; B 95,7 / 92,6 % | A 95,7 / 90,4 %; B 96,7 / 92,6 % | 2 (0,2 %) | 1,5 с |
| Объединение (маска, если сработал любой) | A 99,5 / 98,9 %; B 99,5 / 98,9 % | A 97,8 / 95,2 %; B 98,5 / 96,7 % | 13 (1,3 %) | 1,6 с |

Ложные маски словаря: «Совет», «Плата», «Цена», «Публичная», «Тихая» (совпадают с фамилиями или их основами).
NER: «Машиночитаемая», «Председательствующий» в начале предложения. Хуже всего у всех методов творительный
падеж («подписан …ым …ем …ичем»).

## Вывод

NER заметно лучше на фамилиях не из словаря (90–93 % людей против 64–67 %) при меньшем числе ложных масок.
Объединение даёт лучшую полноту (95–97 % людей на unseen) ценой 1,3 % ложных масок — для принципа «при
сомнении маскировать» это приемлемо: лишняя маска в тексте для модели безопасна. Главный риск NER —
неясная лицензия весов и старые зависимости; словарь чист по лицензии, но сам не дотягивает.
