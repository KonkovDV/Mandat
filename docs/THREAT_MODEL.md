# Модель угроз (черновик для согласования с ИБ банка)

| Угроза | Пример | Мера в коде | Что остаётся |
|---|---|---|---|
| Подделка доверенности | МЧД с чужим доверителем или подписантом | сверка доверителя с клиентом, подписанта с ЕГРЮЛ на дату выдачи, статус в реестре | ГОСТ-проверка КЭП через СКЗИ банка |
| Захват компании через подставного руководителя | смена ЕИО + новая МЧД + смена реквизитов | мониторинг, сценарий `possible_takeover`, приостановка автоматики и удостоверений организации, свежая смена руководителя — «на разбор» | связка с антифродом банка и базой ФинЦЕРТ |
| Действие по оборванной цепочке | основную МЧД отменили, передоверие осталось | каскад п. 3 ст. 188 ГК РФ (R-SUB-006), отзыв удостоверений по событию | задержка поступления события из реестра |
| Устаревшее удостоверение | права проверены месяц назад, МЧД уже отменена | список статусов W3C: проверяющая сторона видит «отозвано» или «приостановлено» | частота обновления списков |
| Отравление документа для модели | инструкции в тексте устава | маркеры данных, модель не меняет вердикт, без цитаты нет факта | — |
| XML-бомба, внешние сущности | DTD с сущностями | `defusedxml`, лимиты размера, глубины, числа элементов | — |
| Обход каталога | `"path": "../../etc/passwd"` | проверка, что путь внутри каталога кейса | — |
| Подмена журнала | правка, удаление, обрезка записей | хеш-цепочка, HMAC (обязателен при `MANDAT_ENV=pilot` и `prod`), файл-свидетель, сверка с внешним корнем Меркла `--merkle-anchor` | регулярная выгрузка корня в СЭД или SIEM банка |
| Подмена удостоверения | правка вердикта в JSON | подпись Ed25519 | публикация открытого ключа банка |
| Утечка ПДн в логи и модель | ИНН в тексте запроса | псевдонимизация, белый список хостов | DLP банка |
| Несанкционированный доступ к API | запрос без токена | API закрыт без токена, сравнение за постоянное время, Swagger выключен по умолчанию | OIDC банка, аудит доступа |
| Подмена чужого кейса | повторный `POST` с тем же `case_id` | 409, перезапись только с `replace=true` | пользователи и роли, `case_id` выдаёт сервер |
| Перегрузка API | поток запросов с одного адреса | 120 запросов в минуту на адрес, тело до 8 МБ, не больше 1000 отчётов в памяти | ограничение на шлюзе банка |
| Доверитель в банкротстве | доверенность выдана после введения процедуры | статус организации в ЕГРЮЛ, порт `BankruptcyPort` под ЕФРСБ | адаптер ЕФРСБ и правило под него |
| Ложное «подтверждено» | реестр недоступен | недоступность = «недостаточно данных», обязательные группы | калибровка на пилоте |
