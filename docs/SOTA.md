# Архитектура против мирового уровня, октябрь 2026

Для каждого направления: что сейчас считается передовым, что из этого взято, что сознательно отложено и почему. Принцип выбора — самое дешёвое решение, которое достаточно для пилота в закрытом контуре банка и не закрывает путь дальше.

## 1. Движок решений

| Вариант | Статус на октябрь 2026 | Сильные стороны | Чего не хватает «Мандату» | Решение |
|---|---|---|---|---|
| Собственное ядро: граф полномочий + правила-данные + свёртка без ложного «да» | текущий | вычисление на дату операции, четыре вердикта, доказательства с XPath и ГРН, правило = норма + тест | формальных гарантий нет | **оставить ядром** |
| Cedar (AWS) | CNCF Sandbox с 08.10.2025; спецификация проверена в Lean, реализация — дифференциальным тестированием | анализируемость, доказуемые свойства политик | только «разрешено/запрещено», нет «на разбор» и «недостаточно данных», нет истории на дату | **взято как независимая проверка**: экспорт ядра передоверия, дифференциальный тест на 384 цепочках (ADR-006) |
| OpenFGA (модель Zanzibar) | CNCF Incubation с 28.10.2025; условные кортежи на CEL | масштаб, граф связей | отвечает «кто имеет доступ сейчас», а не «был ли вправе на дату t»; лишняя инфраструктура | не брать до пилота |
| OPA/Rego, Datalog | зрелые | Datalog естественен для транзитивного передоверия | дублирует граф | возможен как тестовый оракул |

Вывод для жюри: «правила как данные с нормой и тестом, а ключевое свойство передоверия независимо перепроверено на Cedar» звучит сильнее, чем «мы на OpenFGA». Мейнстримные движки авторизации решают задачу доступа, а «Мандат» — задачу юридической действительности полномочия на дату с объяснением.

## 2. Проверяемые удостоверения

| Стандарт | Статус | Что сделано |
|---|---|---|
| W3C Verifiable Credentials Data Model 2.0, Data Integrity 1.0 | Рекомендации W3C с 15.05.2025 | удостоверение о проверке в модели VC 2.0 с доказательством в духе `eddsa-jcs-2022` |
| W3C Bitstring Status List v1.0 | Рекомендация W3C с 15.05.2025 | **добавлено**: списки «отозвано» и «приостановлено», мониторинг выставляет биты по событиям (ADR-007) |
| SD-JWT (RFC 9901) и SD-JWT VC | SD-JWT VC — черновик IETF (draft-19, передан в IESG) | отложено до выхода RFC; альтернативная сериализация того же удостоверения |
| EU Business Wallet, COM(2025) 838 | предложение ЕК от 19.11.2025, позиция Совета ЕС — 09.06.2026 | ориентир: авторизации в кошельке технические и не заменяют законные мандаты национального права — ровно эту границу и закрывает «Мандат» |
| GLEIF vLEI, ISO 17442-3 | действует | ориентир для ролей сотрудников как удостоверений, после пилота |

ГОСТ-подпись. Для боевого контура самописная криптография недопустима: нужны сертифицированные СКЗИ через порт `SignaturePort`. В стенде удостоверения и списки статусов подписаны Ed25519, и отчёт прямо пишет, что это не ГОСТ.

## 3. Журнал и аудит

- **Сделано:** хеш-цепочка с HMAC и файлом-свидетелем.
- **Добавлено:** дерево Меркла по схеме прозрачных журналов (RFC 6962 / RFC 9162). Команда `mandat journal-proof` выдаёт короткое доказательство включения одной записи. Аудитору не нужен весь журнал, а корень дерева можно публиковать во внешнем якоре.
- **Дальше:** публикация корня во внешней системе банка, совместимость с Trillian/Tessera или Rekor v2 — после пилота.

## 4. Языковые модели и документы

- Модель — только советник, и только с дословной цитатой из документа. Это прямо следует из исследований галлюцинаций юридических систем (Stanford, 2024) и из риска инструкций, спрятанных в документе (indirect prompt injection), — `docs/LITERATURE.md`.
- Закон об ИИ 2026 года позволяет ограничивать иностранные модели на чувствительных объектах. Поэтому провайдер сменный (OpenAI-совместимый API в контуре), а по умолчанию нужна российская модель с открытыми весами. Конкретную модель и её лицензию нужно проверить на дату пилота: в этой ревизии лицензии не перепроверялись.
- Сканы бумажных доверенностей: распознавание текста на месте (on-prem OCR) — задача спринта 2. Без него бумажная доверенность всегда уходит на разбор (R-PAP-001).

## 5. Оценка системы с правом воздержаться

Система, которая может сказать «на разбор», оценивается парой «риск — покрытие» (selective classification, Geifman и El-Yaniv, 2017). Покрытие — доля кейсов с автоматическим вердиктом, риск — доля ошибок среди них. `mandat eval` считает обе метрики и верхнюю границу Вилсона для риска. При малой выборке интервалы Вилсона корректнее нормального приближения; конформные методы нужны только после того, как появится вероятностная часть (модель).

## 6. Самый дешёвый достаточный стек для пилота

| Слой | Пилот | Почему достаточно |
|---|---|---|
| Ядро | Python 3.11+, две зависимости (`defusedxml`, `cryptography`) | работает без сети, ставится в закрытом контуре из внутреннего зеркала PyPI |
| Хранилище | PostgreSQL банка: таблицы кейсов и снимков ЕГРЮЛ/реестра с датами действия | история «на дату» без отдельной СУБД |
| Независимая проверка | Cedar (`cedarpy`, Apache-2.0) в CI | без серверов, только тесты |
| Подпись | СКЗИ банка через порт | без закупки новой криптографии |
| Модель | одна небольшая on-prem модель только для устава | без модели продукт работает полностью |
| Интерфейс | API + HTML-карточка, интеграция в существующий экран сотрудника | без нового фронта |

Бизнес-модель — on-prem лицензия с годовой поддержкой и обновлением пакета правил, файла соответствия формату и снимка классификатора («подписка на нормы»). SaaS в контуре банка неуместен.
