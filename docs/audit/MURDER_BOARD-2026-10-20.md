# Murder Board, 20.10.2026

Второй враждебный разбор после [14.10](MURDER_BOARD-2026-10-14.md). Состояние — `main` на `55dcebe`. Шесть позиций: банкир, юрист, правовед, безопасник, ИБ и пользователь. Отдельно — Red Team по бизнес-логике допуска операции и итоговый триаж. Мировая практика, на которую опираются вопросы, — в [срезе 20.10](../research/BANK-PRACTICE-2026-10-20.md).

Шкала серьёзности та же:
- **К** — критично: может убить проект;
- **В** — высокая: снижает балл или блокирует пилот;
- **С** — средняя;
- **Н** — низкая.

Статусы:
- **закрыто** — сделано в коде или документах, указано где;
- **в PR** — исправление ждёт влития;
- **issue** — заведена задача;
- **честный ответ** — исправить нельзя, есть формулировка;
- **банк** — закрывает сторона банка: юрист, ИБ или ИТ.

На 20.10 в коде есть внешний якорь журнала, подписанты PKCS#11, Vault Transit и AWS KMS, разбор человеком через HTTP с очередью и условная заявка `case_id`. Ждут влития строгий JSON на внешних входах ([PR #109](https://github.com/KonkovDV/Mandat/pull/109)), векторы W3C `eddsa-jcs-2022` ([PR #110](https://github.com/KonkovDV/Mandat/pull/110)) и сверка готовности ([PR #108](https://github.com/KonkovDV/Mandat/pull/108)).

## 7. Red Team: допуск операции

Прогон 20.10.2026 на `55dcebe` одноразовым скриптом. Кейс `14_old_director_charter_cleared` даёт «подтверждено» на 20.10.2026. По нему выпущено удостоверение с получателем `dbo` и `nonce`, список статусов свежий, `authorize_operation` вызывается в профиле `demo`. В Windows `fcntl` подменён заглушкой: межпроцессная блокировка для этой проверки не нужна.
