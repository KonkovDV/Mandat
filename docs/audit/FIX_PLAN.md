# План исправлений

Пункты аудита и их статус по коду на 19.10.2026. Сделанное с тестами описано в `AUDIT.md`, порядок работы для ИИ-исполнителя — в [плане работы](../HANDOFF_NEXT_QUOTA.md). Открытых находок с достижимым ложным «подтверждено» в известных сценариях нет, поэтому приоритета P0 в плане нет. P1 — нужно до теневого пилота, P2 — до эксплуатации, P3 — улучшение.

Размер: S — до дня, M — до недели, L — больше недели или нужна внешняя сторона. Нумерация не меняется: на пункты ссылаются другие документы.
