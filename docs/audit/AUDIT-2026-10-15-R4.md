## По позициям

- **Юрист.** Приказ № 1001 уже учтён: паспорт представителя «Мандат» не требует. По 315-ФЗ до 01.09.2027 ничего менять не нужно. Агент не может быть представителем.
- **ИБ.** 15.10 заново прогнаны pip-audit (runtime и dev lock) и Trivy fs: 0 уязвимостей, Dockerfile — 0 проблем конфигурации. Новых зависимостей нет. Защита маршрутов теперь проверяется полным перебором.
- **Банкир.** Порт реестра готов к реальному запросу ФНС. Контракт API лежит в репозитории.
- **Пользователь.** Карточка и вердикты не менялись: R4-1 меняет только параметры запроса.
- **Триаж.** Мутационное тестирование, actionlint и JSON Schema манифеста отложены (см. PORTFOLIO).
- **Red Team.** Может ли подмена представителя в запросе дать чужую МЧД? Нет: ИНН заявителя сверяют отдельные правила личности (R-ID-…), а запрос лишь сужает поиск.
- **Murder Board.** «Без доступа к реестру ФНС это всё ещё заглушка?» Да. Но теперь порт повторяет реальный интерфейс поиска, и адаптер — это транспорт, а не переделка движка.
