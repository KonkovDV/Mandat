## 3. Требования спринта 2

Фокус спринта по условиям трека — «довести MVP, посчитать финансовую модель, показать защиту данных». Новое к нему:

- MVP: допуск операции для ДБО, показ захвата, полный прогон на Linux и Windows — без изменений; правила готовы к датам 315-ФЗ и 253-ФЗ.
- Финансовая модель — без изменений с 17.11.
- Защита данных: поиск секретов по всей истории, страница без внешних запросов, публикация без ключей стенда.
- «Реалистичность пилота»: сроки норм и календарь изменений показывают, что пакет правил не устареет молча в ходе пилота.
