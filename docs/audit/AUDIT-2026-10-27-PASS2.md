# Повторный проход, 27.10.2026

Проверка дерева `1c61c24` после влития [#127](https://github.com/KonkovDV/Mandat/pull/127) и [#128](https://github.com/KonkovDV/Mandat/pull/128). Срезы с датой в имени не переписываются: [глубокая проверка](AUDIT-2026-10-27.md) описывает дыры до исправления, [сверка с эталонами](AUDIT-2026-10-27-DIFFERENTIAL.md) — сами исправления.

Шкала: **К** критично, **В** высокая, **С** средняя, **Н** низкая.

## Что сверено с кодом

| Утверждение сверки | В коде `1c61c24` |
|---|---|
| `1e309` — ошибка входа | `parse_float` отвергает неконечное число |
| Одиночный суррогат — ошибка, U+FFFE остаётся | `_LONE_SURROGATE` и комментарий про Corrigendum #9 |
| Целое 2**53 JCS отвергает, число `float(2**53)` — нет | `MAX_SAFE = 2**53 - 1`; тест оставляет число двойной точности |
| `9999-12-31` и нечитаемый срок — нулевое окно, не исключение | `_authority_end` возвращает уже наступивший конец |
| Смена руководителя отзывает только удостоверения без МЧД | `eio_authority_ended` с `chain_kind=eio_direct`; права по МЧД без `attestation_action` |
| `MANDAT_REQUIRE_ATTESTATION_STATUS=0` в `pilot`/`prod` — ошибка конфигурации | `require_attestation_status` поднимает `ValueError` |
| Метка времени вебхука длиннее 12 цифр — несовпадение, не исключение | `_STAMP` и `_fresh` до сверки подписи |
| Тело разбора читается строго | маршрут использует тот же строгий разбор, что и остальные POST |
| В `evidence.json` 1600 тестов и `collected` 1600 | `--verify-source` сверяет прогон с `pytest --collect-only` |
| Медиана 2,4 мс, 95 % — 3,26 мс | живые формулировки: около 2,5 мс и быстрее 3,5 мс |

Сорок тысяч сравнений с `rfc8785` в этот проход заново не гонялись: их описание и стенд лежат в сверке 27.10.

## Находка

ADR-002 после исправления [#124](https://github.com/KonkovDV/Mandat/issues/124) всё ещё говорил, что мониторинг при смене руководителя ничего не отзывает. Это верно для МЧД и неверно для руководителя без доверенности. Живые границы и C-11 уже различали эти случаи. ADR приведён к коду в этом коммите.

Открыт [#129](https://github.com/KonkovDV/Mandat/pull/129): Dependabot поднимает `setup-python` до 7.1.0 и `codeql-action` до 4.39.1, только закреплённые SHA. В этот коммит не входил.
