# Четвёртый проход: код, логика и вёрстка, 18.11.2026

Объект — код ядра и API после спринта 2, страница проекта и карточки демо. Предыдущий проход — [третий](AUDIT-2026-11-18-PASS3.md).

Метод: полный прогон с покрытием по веткам (1855 тестов, покрытие 94,6 %), чтение модулей, где ошибка стоит денег или доказуемости (допуск операции, удостоверение, свёртка вердикта, горизонт нормы, мониторинг), фаззинг HTTP API и проверка вёрстки на матрице устройств. Роли: интегратор ДБО, служба ИБ, тестировщик веб-студии, фронтенд-разработчик, дизайнер, член жюри.

## 2. Что проверено и ошибок не дало

- Свёртка вердикта: опровержение старше всего, «не проверено» в обязательной группе не даёт «подтверждено», тишина в обязательной группе — пробел, а не «да».
- Горизонт нормы (B8): правило на акте, утратившем силу к дате операции, уходит на разбор; дата «до» — исключительная.
- Допуск операции: `nonce` расходуется только после всех остальных проверок, сумма — целые рубли и не больше проверенной, день — по Москве, неизвестный уровень риска даёт самое строгое окно свежести списков.
- Мониторинг: смена руководителя не отзывает права по МЧД, права руководителя без доверенности отзываются или приостанавливаются, отмена МЧД обрывает передоверие.
- Фаззинг: 52 испорченных тела к четырём методам API, 476 мутаций манифеста и вложенной выписки, 330 мутаций атрибутов МЧД — ни одного ответа 500; 15 вариантов испорченного удостоверения и запроса — отказ или 422, кроме P4-02. Запрос с неизвестным уровнем риска допускается по самому строгому окну свежести списков — так задумано.
- Вёрстка: страница и 14 отчётов на девяти устройствах — от 280 до 2560 px — в светлой и тёмной теме, 144 страницы; нет прокрутки вбок, неудачных запросов, ошибок в консоли и битых якорей.

## 3. Границы

- Вёрстка проверена движком Chromium с эмуляцией устройств; Safari и Firefox на стенде не запускались. Стили используют возможности с запасом: появление разделов по прокрутке есть только там, где браузер поддерживает `animation-timeline`, без неё разделы видны сразу.
- Карточка, которую отдаёт API, остаётся без скриптов, картинок и веб-шрифтов: так требует политика CSP ответа.
