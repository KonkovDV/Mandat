# Сценарий показа

Пять минут на экране. Зритель — жюри трека ВТБ «Финтех без границ». Данные вымышлены. Права в интернет-банке не выдаются.

Перед выходом откройте три HTML и не переключайтесь в редактор. Если сеть в зале пропадёт, страницы уже лежат на диске.

## За двадцать минут до зала

Windows, из корня репозитория:

```powershell
.\run-demo.ps1
```

Или, если пакет уже установлен:

```powershell
mandat demo
```

Не запускайте `monitor` до выхода на сцену. Повтор события ничего не меняет, и живой переход отмены или захвата уже не будет виден. Эти команды — только в разделе «Отмена и захват» ниже.

Откройте в браузере и проверьте, что файлы на месте:

- `var\demo\01_ok.html`
- `var\demo\10_old_director_poa.html`
- `var\demo\05_director_changed.html`

Каталог `var\` в git не хранится. Без этой команды показывать нечего.

## Порядок

### 1. Вопрос, не продукт

Фраза: «Сотрудник банка сегодня сам сводит МЧД, ЕГРЮЛ и устав и решает, можно ли этому человеку подписать платёж от имени компании на эту дату. Мы отвечаем на этот вопрос одним из четырёх вердиктов и показываем, из какого поля он взят».

Не говорить: что система внедрена, одобрена или уже стоит в ВТБ.

### 2. Кейс без опровержения — `01_ok.html`

Показать вердикт «НА РАЗБОР», строку про устав, плашку «Режим стенда» и цепочку.

Фраза: «Опровержения нет: представитель и срок сходятся. Но шаблоны не классифицировали устав, поэтому автоматического подтверждения нет. Плашка стенда говорит, что реестр и ЕГРЮЛ взяты из пакета кейса, а не из ФНС».

Если спросят про подпись: порт есть, без СКЗИ банка статус всегда «не проверено». В профиле `strict` без этой проверки «подтверждено» не ставится.

### 3. Давняя смена руководителя — `10_old_director_poa.html`

Фраза: «Директор сменился почти полгода назад. По пункту 1 статьи 188 Гражданского кодекса и позиции ФНС доверенность от этого не прекращается. Это сигнал, не отказ».

Не произносить формулу из запрещённого списка, будто смена руководителя сама гасит доверенность.

### 4. Свежая смена — `05_director_changed.html`

Фраза: «Здесь смена свежая. Тот же закон, другой риск: так начинается захват через подставного руководителя. Кейс уходит на разбор, с маршрутом и сроком. Человек решает».

### 5. Отмена и захват — терминал

Отмена основной МЧД:

```powershell
mandat monitor examples/events/poa_revoked.json --status-dir var/demo/status
mandat attest-verify var/demo/attestations/03_subdelegation_ok.json --public-key (Get-Content var/demo/public_key.txt) --status-dir var/demo/status
```

Фраза: «Основную доверенность отменили. Передоверие теряет силу вместе с ней, пункт 3 статьи 188. Удостоверение проверки перешло в статус „отозвано“. Права в интернет-банке мы не трогаем: на пилоте режим теневой».

Захват:

```powershell
mandat monitor examples/events/takeover.json --status-dir var/demo/status
```

Фраза: «За короткое окно совпали смена руководителя, новая МЧД и заявка на смену реквизитов. Удостоверения организации приостановлены. Это повод для антифрода, не автоматический отказ всем клиентам».

Порядок событий внутри окна не важен: смена руководителя может прийти последней. Отмена МЧД в той же пачке не теряется за тревогой о захвате.

### 6. Журнал, одна запись

```powershell
mandat journal-proof var/demo/journal.jsonl --seq 3
```

Фраза: «Аудитору можно доказать, что решение есть в журнале, не отдавая журнал целиком. Подмена одной строки ломает цепочку. Подмена файла вместе со свидетелем ловится, только если последний хеш хранится вне системы. Пока корень никуда не публикуется».

## Если спросят

| Вопрос | Ответ | Куда ткнуть, если попросят файл |
|---|---|---|
| Это точность 100%? | Нет. 294 из 294 — согласие движка с дефектом, который мы сами заложили в генератор. На документах банка это не измерялось | [CLAIMS_REGISTRY.md](../CLAIMS_REGISTRY.md), C-03 |
| Реестр ФНС уже всё проверяет? | Статус МЧД — одно правило из 32. Рядом передоверие, срок, смена руководителя, устав и покрытие операции | [конкуренты](COMPETITORS.md) |
| Модель принимает решение? | Нет. Правила сворачивают вердикт. Модель может предложить цитату из устава. Без цитаты факта нет | [ADR-001](adr/ADR-001-verdict-ownership.md) |
| Оценка по 152-ФЗ уже есть? | Нет. Спроектировано для контура банка: без сети, с псевдонимизацией номеров. Оценку соответствия не проходили | [защита данных](DATA_PROTECTION.md), [границы](../LIMITS.md) |
| КЭП проверены? | Нет. Порт ждёт СКЗИ банка | [границы](../LIMITS.md) |
| Что будет на пилоте? | Шесть недель в тени: те же пакеты, что у сотрудника, на выдачу прав не влияет. Ноль ложных «подтверждено» на всех кейсах пилота — стоп-критерий | [пилот](PILOT.md) |

Полный список фраз, которые нельзя произносить, — [BANNED_CLAIMS.txt](../BANNED_CLAIMS.txt). Как сказать вместо них — нижняя таблица [реестра](../CLAIMS_REGISTRY.md).
