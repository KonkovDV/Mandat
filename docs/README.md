## Решения

Короткие ADR лежат в [docs/adr](adr/): владение вердиктом, смена руководителя, правила как данные, подпись удостоверения, модель в контуре, Cedar, списки статусов, форматы МЧД.

## Чего в этой карте нет

Официальных критериев оценки трека: в открытых источниках их не нашли, это записано в [сдаче](../submission/README.md). Пока их нет, показ строится вокруг бизнес-задачи, а не вокруг чек-листа организатора.
