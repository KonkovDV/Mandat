# План перехода R-FMT-001 под 315-ФЗ (до 01.09.2027)

**Норма:** Федеральный закон от 04.08.2026 № 315-ФЗ «О внесении изменений в Федеральный закон „Об электронной подписи“»  
([publication.pravo.gov.ru/document/0001202608040021](http://publication.pravo.gov.ru/document/0001202608040021)).  
**Вступление в силу:** 01.09.2027 (ст. 2 315-ФЗ).  
**Что меняется:** ч. 1 ст. 17.5 63-ФЗ — по общему правилу МЧД представляется в **единой форме**, формируемой и размещаемой уполномоченным органом на ЕПГУ; формы операторов ГИС, Банка России (участники финансового рынка) и ФНП становятся **дополнительными**.

R-FMT-001 сейчас принимает единый формат 003 (EMCHD) и отмечает пробелы XSD. До 01.09.2027 код **не** меняем: клиенты банка — не участники финансового рынка, вход остаётся формат 003 ([REGULATORY.md](../REGULATORY.md), [ADR-008](../adr/ADR-008-formats-and-classifier.md)).

## Объём изменений в коде (оценка)

1. **Парсер** — новый профиль в `intake/` (не ломать 003): namespace, обязательные поля, признаки передоверия/безотзывности.
2. **R-FMT-001** — `format_gaps` / `policy_gaps` по новой схеме; сообщения без привязки только к «003».
3. **R-FMT-002** — критерий «единый формат» = ЕПГУ-форма после даты; 003 — legacy или доп. форма по решению юриста.
4. **Классификатор** — без изменений, если ст. 17.1 сохраняет отсылку к классификатору полномочий.
5. **Реестр** — проверить, что поиск по номеру + ИНН доверителя + ИНН представителя остаётся достаточным для новой формы.

## Что не входит в стенд (сторона банка)

- Получение XSD и ключей от оператора / Госуслуг.
- СКЗИ и проверка КЭП по ст. 11 63-ФЗ.
- Утверждение правил юристом (`draft` → `approved`).
- Политика: принимать ли действующие МЧД формата 003 после 01.09.2027 до истечения срока (переходных положений в 315-ФЗ нет — см. LEGAL_REVIEW).

## Статус на 15.10.2026

План зафиксирован. Реквизиты 315-ФЗ сверены с publication.pravo.gov.ru ([П-рекв]). Текст новой ч. 1 ст. 17.5 — по consultant.ru / обзорам будущей редакции ([В] до выгрузки полного текста с pravo в машиночитаемом виде для цитирования в ADR). Код R-FMT-001 не менялся.
