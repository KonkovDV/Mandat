## Сделано

- Смена руководителя — сигнал, а не прекращение доверенности; свежая смена идёт на разбор (п. 1 ст. 188 ГК РФ, [ADR-002](adr/ADR-002-director-change.md)).
- Отмена основной МЧД обрывает передоверие (п. 3 ст. 188 ГК РФ); мониторинг отзывает удостоверения по всей цепочке.
- Признаки передоверия, утраты полномочий и совместных полномочий; реквизиты по Приказу Минцифры № 1001 в редакции на дату выдачи; срок по закону для МЧД без срока.
- Пути полей сверены с XSD `EMCHD_1` ([формат](FORMAT_NOTES.md)); классификатор полномочий с датами действия кодов и импорт из ЕСНСИ.
- Свойство передоверия перепроверено второй реализацией на Cedar на 384 цепочках, включая форму передоверия.
- Удостоверение привязано к запросу операции: организация, день, сумма, представитель, получатель и одноразовый `nonce`. ДБО спрашивает допуск по HTTP, повтор получает отказ с временем первого допуска ([RUN](RUN.md#допуск-операции-для-дбо)).
- `mandat showcase` одной командой показывает, как захват компании останавливается до платежа.
- Правило утверждает только подписанная запись юриста ([ADR-009](adr/ADR-009-rule-approval-records.md)); на каждое правило есть карточка нормы ([пакет для юриста](legal/README.md)).
- Пакет правил знает сроки актов: 315-ФЗ, 253-ФЗ, приказы Минцифры № 856 и № 857 ([ADR-010](adr/ADR-010-norm-validity.md)).
- Защита данных: персональные данные заменяются метками до модели, каждое чтение отчёта пишется в журнал, кейс удаляется по основанию из 152-ФЗ, записи хранилища зашифрованы ([защита данных](DATA_PROTECTION.md)).
- Ключ подписи удостоверений — в HSM, Vault Transit или AWS KMS; внешний якорь журнала — файл, вебхук, метка времени RFC 3161 или Rekor ([ключи](KEYS.md)).
- Разбор кейса через HTTP: очередь, роли из токена, сроки ([разбор](REVIEW.md)).
- Полный набор тестов идёт в CI на Linux и Windows; поиск секретов gitleaks — по всей истории git.
