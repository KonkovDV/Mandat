# Дорожная карта

Что уже сделано и что осталось до финала соревнования и до пилота. Главное: ядро проверки, мониторинг и журнал готовы; не хватает реальных источников (реестр, ЕГРЮЛ, СКЗИ), кодов полномочий банка и проверки на реальных пакетах.

Сроки этапов — по сайту соревнования fintechacademy.ru: онлайн-питчи 10–15 ноября, второй спринт 16–29 ноября, третий 3–8 декабря, финал 11 декабря 2026.

## Сделано

- Смена руководителя — сигнал, а не прекращение доверенности; свежая смена идёт на разбор (п. 1 ст. 188 ГК РФ, [ADR-002](adr/ADR-002-director-change.md)).
- Отмена основной МЧД обрывает передоверие (п. 3 ст. 188 ГК РФ); мониторинг отзывает удостоверения по всей цепочке.
- Признаки передоверия, утраты полномочий и совместных полномочий; реквизиты по Приказу Минцифры № 1001; срок по закону для МЧД без срока.
- Сверка путей полей с XSD `EMCHD_1` ([формат](FORMAT_NOTES.md)).
- Классификатор полномочий с датами действия кодов и импорт из ЕСНСИ.
- Отзыв и приостановка удостоверений по событиям, журнал с доказательством включения записи.
- Перепроверка свойства передоверия на 384 цепочках второй реализацией на Cedar.
- Плашка «Режим стенда» в каждом отчёте.

## До финала

- [ ] Запросить XSD `EMCHD_1` у оператора реестра и подтвердить, что открытая копия действующая.
- [ ] 8–12 интервью и опрос ([discovery](discovery/)); запросить у организатора критерии оценки трека.
- [ ] Видео-демо: кейсы 01, 05, 10, 11 и мониторинг.
- [ ] Прототип проверки КЭП через СКЗИ банка.
- [ ] Расчёт эффекта на цифрах из интервью ([экономика](ECONOMICS.md)).
- [ ] Контракт интеграции с ДБО (OpenAPI) и сценарий пилота.

## К пилоту

- [ ] Коды полномочий из выгрузки ЕСНСИ по выбору банка.
- [ ] Корпус от 300 пакетов с независимой разметкой и сравнение «вручную против „Мандата“».
- [ ] Извлечение ограничений устава моделью с обязательной цитатой; распознавание сканов.
- [ ] ГОСТ-подпись удостоверений через СКЗИ банка.
- [ ] Доказательство свойства передоверия для любых входов (символьный анализ Cedar).

## Потом

Очередь исключений с назначением сотрудников, публикация корня журнала вне системы, роли сотрудников как проверяемые удостоверения по образцу GLEIF vLEI.
