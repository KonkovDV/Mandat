# ADR-001. Вердикт формируют правила, модель только советует

**Контекст.** Банку нужен объяснимый результат, за который отвечает человек. Банк России в консультационном докладе об ИИ (20.11.2025) относит объяснимость к модельным рискам, а прозрачность и человекоцентричность называет принципами доверенного ИИ. Языковая модель может ошибиться в фактах и поддаётся инструкциям, спрятанным в тексте документа.

**Решение.**
- Вердикт вычисляет `domain/verdict.fold` только по находкам детерминированных правил.
- Находки модели получают происхождение `advisory` и эффект «справка»; свёртка их не учитывает (`effective_effect`).
- Кандидатный факт модели принимается, только если его цитата дословно есть в документе и уверенность выше порога (`advisory/gate.ground_candidates`).
- Константы `LLM_WRITES_VERDICT = False`, `LLM_SELECTS_RULES = False`, список `FORBIDDEN_LLM_ACTIONS`.

**Проверка.** Тесты `test_advisory_cannot_change_verdict`, `test_advisory_finding_cannot_change_verdict`, `test_gate_drops_ungrounded_and_unsure_candidates`.

**Последствия.** Модель полезна там, где текст не формализован: устав, бумажная доверенность, текстовые полномочия. Там она ускоряет работу сотрудника, но кейс всё равно уходит на разбор.
