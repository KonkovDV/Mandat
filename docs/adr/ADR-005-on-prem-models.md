# ADR-005. Модели — только в контуре банка и по белому списку хостов

Решение: модель-советник выключена по умолчанию, ходит только на разрешённые хосты внутри контура и получает текст, в котором ФИО заменены метками, а реквизиты — псевдонимами. Без модели продукт работает полностью.

**Контекст.** Данные клиентов не должны уходить за периметр банка. Официальных критериев трека мы не нашли. Закон о технологиях ИИ (243-ФЗ, подписан 26.07.2026, [kremlin.ru](http://kremlin.ru/acts/bank/53467)) поручает Президенту определять случаи, когда допускаются только суверенные или национальные модели; для банковской сферы эти случаи согласуются с Банком России (ст. 5). Перечня таких случаев мы пока не видели.

**Решение.**
- `advisory/llm.OpenAICompatClient` работает с любым OpenAI-совместимым сервером в контуре (vLLM, llama.cpp).
- Пока не задан `MANDAT_LLM_BASE_URL`, модель выключена. Хост должен быть в `MANDAT_LLM_ALLOWED_HOSTS` (по умолчанию localhost).
- Перед отправкой ФИО заменяются метками, реквизиты псевдонимизируются, документ обрамляется маркерами данных, `temperature = 0`.
- Модель выбирает банк, провайдер сменный. Кандидаты — российские модели с открытыми весами и модели, которые банк уже применяет. Лицензии конкретных моделей не проверены.
- Модель только советует, вердикт не меняет, автоматическое решение можно оспорить у человека ([AI_RISKS](../AI_RISKS.md)).

**Последствия.** Без модели ограничения устава ищутся шаблонами, а текстовые полномочия уходят на разбор.
