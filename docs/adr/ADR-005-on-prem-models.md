# ADR-005. Модели — только в контуре банка и по белому списку хостов

Решение: модель-советник выключена по умолчанию, ходит только на разрешённые хосты внутри контура и получает текст, в котором ФИО заменены метками, а реквизиты — псевдонимами. Без модели продукт работает полностью.

**Контекст.** Данные клиентов не должны уходить за периметр банка. Трек ставит то же условие: генеративный ИИ — на российских или on-prem моделях ([условия](https://fintechacademy.ru/task-1)). Закон о технологиях ИИ (243-ФЗ, подписан 26.07.2026, [kremlin.ru](http://kremlin.ru/acts/bank/53467)) поручает Президенту определять случаи, когда допускаются только суверенные или национальные модели; для банковской сферы эти случаи согласуются с Банком России (ст. 5). Когда перечень утвердят, выбор модели сверяется с ним: провайдер меняется одной настройкой.

**Решение.**
- `advisory/llm.OpenAICompatClient` работает с любым OpenAI-совместимым сервером в контуре: vLLM, llama.cpp или Ollama.
- Без `MANDAT_LLM_BASE_URL` модель выключена. Хост должен быть в `MANDAT_LLM_ALLOWED_HOSTS` (по умолчанию localhost).
- Перед отправкой ФИО заменяются метками, реквизиты псевдонимизируются, документ обрамляется маркерами данных, `temperature = 0`.
- Модель выбирает банк, провайдер сменный. Команда замерила двух кандидатов с открытыми весами под лицензией Apache-2.0: Mistral Small 3.2 — модель стенда, встаёт на одну видеокарту; российская `t-tech/T-lite-it-2.1` — около 6 ГБ видеопамяти в квантизации GGUF Q4_K_M ([замеры](../ADVISORY_MODELS.md)). Подходит и модель, которую банк уже применяет, если она отвечает по OpenAI-совместимому интерфейсу.
- Модель только советует, вердикт не меняет, автоматическое решение можно оспорить у человека ([AI_RISKS](../AI_RISKS.md)).

**Последствия.** Без модели ограничения устава ищутся шаблонами, а текстовые полномочия уходят на разбор.
