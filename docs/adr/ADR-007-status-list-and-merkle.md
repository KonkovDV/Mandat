# ADR-007. Статус удостоверений и доказуемый журнал

Решение: статус удостоверения публикуется в подписанных списках W3C Bitstring Status List, а над журналом строится дерево Меркла. Проверяющий видит отзыв без доступа к базе, аудитор получает доказательство одной записи без всего журнала.

**Контекст.** Удостоверение живёт дольше проверки: МЧД отменяют, руководитель меняется, начинается захват компании.

**Решение.**
- Bitstring Status List v1.0 (Рекомендация W3C с 15.05.2025). `credentialStatus` указывает бит в двух списках, `revocation` и `suspension`. Список — подписанный `BitstringStatusListCredential` на 131 072 бит, GZIP, multibase base64url. Номера битов случайные, чтобы по ним нельзя было судить о порядке выдачи (`audit/status_list.py`).
- Биты выставляет мониторинг. Отмена или истечение МЧД — `revocation` для удостоверений с этой МЧД в цепочке. Признаки захвата — `suspension` для всех неопровергнутых удостоверений организации.
- Дерево Меркла по RFC 9162 (`audit/merkle.py`). `mandat journal-verify` печатает корень, `mandat journal-proof --seq N` выдаёт доказательство включения из log2(n) хешей. Хеш-цепочка с HMAC остаётся.

**Проверка.** `test_bitstring_encoding_follows_w3c_layout`, `test_status_list_revocation_is_signed_and_checked`, `test_monitor_revokes_and_suspends_attestations`, `test_merkle_inclusion_proofs_for_every_size`, `test_journal_proof_cli`.

**Ограничения.** Подпись Ed25519, не ГОСТ. Совместимость с внешними верификаторами не проверялась. Утверждение о каждом закрытом сегменте (хеш последней записи и корень Меркла сегмента) уходит во внешний якорь, только если он задан (`audit/anchor.py`, [внешний якорь](../KEYS.md#внешний-якорь-журнала)); приёмник в контуре выбирает банк.
