# ADR-004. Результат проверки — подписанное удостоверение

**Контекст.** Результат проверки нужен другим системам банка (ДБО, антифрод, аудит), и проверять его хочется без доступа к базе «Мандата». Мировой ориентир — роли сотрудников как проверяемые удостоверения (GLEIF vLEI, ISO 17442-3).

**Решение.** На каждый отчёт выпускается JSON в модели W3C Verifiable Credentials 2.0 с доказательством Data Integrity в духе `eddsa-jcs-2022`: хеш конфигурации доказательства и хеш документа, подпись Ed25519, значение в base58btc. В удостоверении — ИНН организации, хеш ИНН представителя, операция, вердикт, профиль, хеш набора правил, хеш отчёта и хеши входных документов. ФИО и паспортных данных нет.

**Проверка.** `test_attestation_sign_verify_and_tamper`, команда `mandat attest-verify`.

**Ограничения.** Совместимость с внешними верификаторами VC не проверялась. Издатель — `did:web:mandat.example`, в пилоте — ключ и идентификатор банка. Идея перенесена из fsp-talent (ADR-0007).
