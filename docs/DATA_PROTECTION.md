# Защита данных

«Мандат» обрабатывает персональные данные представителей и руководителей: ФИО, ИНН, СНИЛС, должность. Ниже — что уже сделано в коде и что нужно для пилота. Это описание проектных решений, а не юридическая оценка соответствия: её даёт служба ИБ и юристы банка.

## Уже в коде

| Мера | Где |
|---|---|
| Работа без сети: ядро не делает внешних запросов | `intake`, `rules`, `services` |
| Модель — только хосты из `MANDAT_LLM_ALLOWED_HOSTS` (по умолчанию localhost), выключена по умолчанию | `advisory/llm.py` |
| Псевдонимизация ИНН, СНИЛС, паспорта, телефона и почты перед отправкой в модель (HMAC, ключ `MANDAT_PII_KEY`) | `privacy/pii.py` |
| В подписанном удостоверении нет ФИО, только хеш ИНН представителя | `audit/attestation.py` |
| Номера в списках статусов выдаются случайно: по номеру нельзя судить о порядке и времени выдачи | `audit/status_list.py` |
| Доказательство включения записи журнала раскрывает одну запись, а не весь журнал | `audit/merkle.py` |
| Представитель сверяется по СНИЛС или ИНН, паспортные данные для проверки не нужны (Приказ Минцифры № 1001) | `rules/checks.py`, R-ID-003 |
| Защита от XML-бомб и внешних сущностей, лимиты размера | `intake/xml_safety.py` |
| Пути документов не выходят за каталог кейса | `intake/case_loader.py` |
| API закрыт без токена, лимит тела запроса, `no-store`, CSP на HTML-отчёте | `api/app.py` |
| Журнал решений с обнаружением изменений (хеш-цепочка, HMAC, свидетель; не защита от изменения и не самостоятельное доказательство) | `audit/journal.py` |
| Разработка и демо — только на синтетических данных | `eval/synth.py`, `examples/` |

## Для пилота

- Хранилище кейсов в контуре банка, сроки хранения отчётов и удаление по запросу субъекта.
- Ключи `MANDAT_JOURNAL_KEY`, `MANDAT_PII_KEY` и ключ подписи удостоверений — в хранилище секретов банка; ключ разработки в пилоте запрещён.
- OIDC банка вместо статического токена, роли «оператор», «юрист», «комплаенс», «ИБ».
- Модель угроз (`docs/THREAT_MODEL.md`) — на согласование с ИБ банка; ориентиры — ГОСТ Р 57580.1 и требования к защите ПДн; перечень применимых мер определяет банк.
- Логи без ПДн: в журнал попадают хеши отчётов и идентификаторы кейсов, а не документы.
