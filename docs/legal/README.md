# Пакет для юриста банка

> Собран командой `python scripts/gen_norm_cards.py`. Руками не правится.

Карточка нормы на каждое из 39 правил пакета `mandat-rules-ru` (версия `2026.10.2`). Юрист читает карточку, сверяет норму по первоисточнику и решает: утверждаю, утверждаю с правкой или отклоняю. Утверждение — подписанная запись под хешем из карточки ([ADR-009](../adr/ADR-009-rule-approval-records.md), [как утвердить](../LEGAL_REVIEW.md#как-утвердить-правило)).
