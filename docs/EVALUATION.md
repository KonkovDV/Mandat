# Оценка качества

Как мы проверяем «Мандат» и что значат цифры. Главный вывод: на синтетическом корпусе из 294 кейсов ложных «подтверждено» нет (0 из 288, верхняя граница 1,3 %), а 38,8 % кейсов решаются без человека, и ошибок среди них нет. Корпус и движок пишет одна команда, поэтому это проверка логики правил; точность на документах банка измеряет теневой пилот по готовому протоколу ([PILOT](PILOT.md)).

Все числа ниже — из `evidence.json` (собирается `python scripts/build_evidence.py`, последняя сборка 16.10.2026). Номера C-xx — строки [реестра утверждений](../CLAIMS_REGISTRY.md).

## Синтетический корпус

`mandat eval --per-defect 6` собирает 294 кейса: 49 видов по 6 кейсов (`src/mandat/eval/synth.py`). Для каждого вида заранее записан ожидаемый вердикт:

| Ожидаемый вердикт | Видов | Примеры |
|---|---|---|
| опровергнуто | 18 | МЧД отменена или истекла, передоверие запрещено, шире или дольше родительской, чужой представитель, ликвидация |
| на разбор | 21 | свежая смена руководителя, порог в уставе, текстовое полномочие, нет МЧД в реестре, а также пять «чистых» сценариев без дефекта |
| недостаточно данных | 9 | реестр не ответил, нет родительской МЧД, битый XML, XML-бомба, устаревшая выписка ЕГРЮЛ (Единый государственный реестр юридических лиц) |
| подтверждено | 1 | `ok_charter_cleared`: чистый кейс с синтетической отметкой «ограничений устава нет» |

Пять чистых сценариев идут на разбор, потому что шаблоны не смогли разобрать устав, а для подписи платежей он обязателен (правило R-CHR-002). Единственный путь к «подтверждено» в корпусе — отметка об уставе в манифесте кейса. Ей верит только профиль `demo`; в банке её место займёт запись согласования юриста ([вопросы юристу](LEGAL_REVIEW.md)).

## Как считаются границы

При нуле ошибок из n случаев верхняя граница 95 % считается по формулам ниже. n — число случаев, в которых ошибки не было. Проверка чисел — `tests/test_m08_eval_bounds.py`.

Двусторонняя граница Клоппера — Пирсона. Её считает `run_corpus`, это число в `evidence.json`:

верхняя граница = 1 − 0,025 в степени (1 / n)

Односторонняя граница 95 %:

верхняя граница = 1 − 0,05 в степени (1 / n)

«Правило трёх», приближение односторонней границы:

верхняя граница = 3 / n

| Метод | 0 из 48 видов | 0 из 288 кейсов |
|---|---|---|
| Двусторонняя граница Клоппера — Пирсона | 7,4 % (7,40) | 1,3 % (1,27) |
| Интервал Уилсона, двусторонний 95 % | 7,4 % (7,41) | 1,3 % (1,32) |
| Односторонняя граница 95 % | 6,1 % (6,05) | 1,0 % (1,03) |
| Правило трёх | 6,25 % | 1,04 % |

В текстах указана двусторонняя граница Клоппера — Пирсона: она строже односторонней. Уилсон приведён для сравнения. При ненулевом числе ошибок `clopper_pearson` (`src/mandat/eval/metrics.py`) ищет границу бисекцией по функции распределения биномиального закона, без внешних библиотек. Граница риска решений без человека (C-05, 0 из 114) по тому же методу — 3,2 %.

## Свойство передоверия

`tests/test_properties.py` перебирает все двухзвенные цепочки малого домена: 8 наборов кодов родителя × 8 наборов кодов передоверия × 3 значения признака передоверия × 2 варианта срока = 384 цепочки. «Подтверждено» должно выходить тогда и только тогда, когда передоверие разрешено, не шире и не дольше родительской МЧД и покрывает операцию. `tests/test_cedar.py` проверяет то же второй реализацией на языке политик Cedar: решения совпадают на всех 384 цепочках (C-06, [ADR-006](adr/ADR-006-decision-engine.md)). Это перебор, а не доказательство для любых входов.

## Как получить честную оценку на пилоте

1. **Независимая разметка.** Два эксперта, один из них юрист, размечают пакеты, не видя ответа движка. Согласие считается по κ Коэна, расхождения разбирает третий.
2. **Объём.** Чтобы оценить полноту около 0,9 с точностью ±5 % при 95 %, нужно не меньше 139 случаев с дефектом (`required_n(0.9, 0.05)`).
3. **Устав и сканы.** Извлечение из устава и бумажных доверенностей меряется отдельно, по полям.
4. **Люди.** Одни и те же сотрудники проверяют пакеты вручную и с «Мандатом» в уравновешенном порядке. Время сравнивается тестом Вилкоксона, ошибки — тестом Мак-Немара.
5. **Стоп-критерий.** Ни одного ложного «подтверждено» за весь пилот ([пилот](PILOT.md)).
