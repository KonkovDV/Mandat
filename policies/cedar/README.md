# Политики Cedar

Здесь лежит вторая, независимая реализация правил передоверия на языке Cedar. Она нужна только для перекрёстной проверки: ядром «Мандата» Cedar не становится ([ADR-006](../../docs/adr/ADR-006-decision-engine.md)).

`mandat.cedar` и `mandat.cedarschema` генерирует `python scripts/export_cedar.py` из каталога операций и снимка классификатора. Руками их не правят.

Проверяемое свойство: передоверие не расширяет полномочия, не продлевает срок и не обходит запрет передоверия.
- `tests/test_cedar.py` прогоняет политики через валидатор Cedar и сравнивает решения с вердиктами «Мандата» на всех 384 двухзвенных цепочках. Нужен extra `cedar`: `pip install -e ".[cedar]"`.
- `tests/test_properties.py` проверяет то же свойство без Cedar, по закрытой формуле.
