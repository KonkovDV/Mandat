# Политики Cedar

Файлы `mandat.cedar` и `mandat.cedarschema` сгенерированы командой `python scripts/export_cedar.py` из каталога операций и снимка классификатора. Вручную их не правят.

Зачем они нужны. Cedar отвечает только «разрешено» или «запрещено», а «Мандату» нужны ещё «на разбор» и «недостаточно данных». Поэтому ядром Cedar не становится (ADR-006). Зато на нём удобно независимо перепроверить главное свойство: передоверие не расширяет полномочия, не продлевает срок и не обходит запрет передоверия.

Что проверяется:

- `tests/test_cedar.py` проверяет политики по схеме (валидатор Cedar) и сравнивает решения Cedar с вердиктами «Мандата» на всех 384 двухзвенных цепочках. Нужен extra `cedar`: `pip install -e ".[cedar]"`.
- `tests/test_properties.py` проверяет то же свойство без Cedar, по закрытой формуле.

Следующий шаг (P2) — доказать свойство для всех входов, а не только для перебора, через символьный анализ Cedar (SMT).
