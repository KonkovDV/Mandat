## Критерии спринта 2

По странице [fintechacademy.ru/task-1](https://fintechacademy.ru/task-1) на 17.11.2026: шесть критериев, сумма — 100 баллов, по ним выбирают финалистов. Описаний критериев на странице нет, положение соревнования (Яндекс Диск) мы открыть не смогли: формулировки ниже — только названия и максимумы. Технические условия трека: решение для российского рынка, работа в закрытом контуре банка при доступе к данным клиентов, генеративный ИИ — на российских или локальных моделях.

| Критерий | Баллы | Чем отвечает репозиторий | Чего нет |
|---|---|---|---|
| Данные, безопасность и комплаенс | 0–18 | ядро без внешней сети (C-12); ФИО и номера заменяются метками до модели ([защита данных](../docs/DATA_PROTECTION.md)); журнал с HMAC и деревом Меркла, внешний якорь (C-09); ключи в HSM, Vault или KMS ([ключи](../docs/KEYS.md)); строгий JSON и контракт манифеста; правило утверждает только подписанная запись юриста (C-20, [ADR-009](../docs/adr/ADR-009-rule-approval-records.md)); pip-audit, Trivy, CodeQL, Scorecard, поиск секретов gitleaks по всей истории git, SBOM и подписанное происхождение сборки, CI и по расписанию ([SECURITY](../SECURITY.md)) | проверка КЭП через СКЗИ банка; оценка соответствия 152-ФЗ и ГОСТ Р 57580.1 — за банком ([матрица требований](../docs/research/REQUIREMENTS_MATRIX.md)) |
| Техническая реализация, автоматизация и масштабирование | 0–22 | 39 правил и четыре вердикта, CLI и HTTP API с ролями; допуск операции для ДБО через HTTP с атомарным одноразовым `nonce` (C-18); хранилища в памяти, SQLite и Redis, несколько воркеров и машин; Docker и пилотный compose с `/readyz`; проверка кейса — менее 3 мс (C-14); вся цепочка от проверки до отказа платежу после захвата — одной командой `mandat showcase` (C-22); все автотесты проходят на Linux и Windows (C-13) | нагрузочный замер на контуре банка |
| Оценка ценности (unit-экономика или эффект и ROI) | 0–22 | финансовая модель на формулах: три сценария, эффект для ВТБ, окупаемость разовых затрат, отдача за 3 года, NPV и IRR, чувствительность ([пакет аналитики](analytics/README.md), C-15, C-16); юнит-экономика одной проверки: вручную около 540 ₽, затраты банка на «Мандат» около 64 ₽ ([экономика](../docs/ECONOMICS.md#юнит-экономика-одной-проверки), C-21) | доли событий и минуты на кейс — допущения команды; эффект на данных банка — на пилоте |
| Зрелость решения и прогресс по доработке продукта | 0–16 | что сделано за спринт — [журнал изменений](../CHANGELOG.md) и [ключевые результаты](FORM_SPRINT2.md); каждое число — из `evidence.json` с командой воспроизведения | — |
| Подтверждённость проблемы, ценности и рынка | 0–12 | данные Банка России за I полугодие 2026 года (M-07, M-15), реальные дела («ЭОС», ВС РФ № 308-ЭС22-17199), FATF R10 и AMLR ЕС (M-12, M-13), рынок TAM, SAM, SOM двумя способами ([рынок](analytics/README.md)) | интервью с сотрудниками банка и клиентами — за владельцем ([discovery](../docs/discovery/)) |
| Реалистичность пилота и готовность к внедрению | 0–10 | шестинедельный теневой пилот ([пилот](../docs/PILOT.md)); порты к реестру МЧД, ЕФРСБ и СКЗИ; контракт для ДБО; [пакет для юриста](../docs/legal/README.md); сроки норм в пакете правил: правило на утратившем силу акте «подтверждено» не даёт, `mandat law-calendar` предупреждает заранее ([ADR-010](../docs/adr/ADR-010-norm-validity.md)); [ступени готовности](../docs/audit/READINESS_GATES.md) | владелец процесса в банке, обезличенные пакеты, решение юриста по правилам |

## Перед каждой сдачей

```bash
make check        # ruff, тесты, проверка формулировок
make evidence     # пересобрать evidence.json
mandat demo       # отчёты для показа
make submission   # модель, колода, видео, документы и папка для облачного диска в var/submission
```
