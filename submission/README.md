По данным bankinform.ru, призовой фонд — 1,5 млн руб. на шесть команд, а победители могут пройти отбор в акселератор ВТБ или бизнес-инкубатор университета. Официальные критерии оценки трека в открытых источниках не найдены: запросить у организатора. Ориентир из слов организатора — «не тестовое задание, а реальная бизнес-задача» (aif.ru).

## Чек-лист перед каждой сдачей

```bash
make check        # ruff, тесты, контроль формулировок, документ правил
make evidence     # пересобрать evidence.json
mandat demo       # отчёты для показа
```

Каждое число на слайде есть в `CLAIMS_REGISTRY.md` и воспроизводится командой из него.
