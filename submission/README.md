## Чек-лист перед каждой сдачей

```bash
make check        # ruff, тесты, контроль формулировок, документ правил
make evidence     # пересобрать evidence.json
mandat demo       # отчёты для показа
```

Каждое число на слайде есть в `CLAIMS_REGISTRY.md` и воспроизводится командой из него.

## Сценарий демо на 3 минуты

1. `var/demo/01_ok.html` — подтверждено: цепочка «руководитель → МЧД», каждое поле со ссылкой на XPath и ГРН, плашка «Режим стенда» честно показывает заглушки.
2. `var/demo/10_old_director_poa.html` — подтверждено с сигналом: директор сменился почти полгода назад, МЧД не отменена — по ст. 188 ГК РФ она действует.
3. `var/demo/05_director_changed.html` — на разбор: директор сменился 19 дней назад, это первый шаг возможного захвата; маршрут и срок.
4. `mandat monitor examples/events/poa_revoked.json --status-dir var/demo/status` — основную МЧД отменили: передоверие теряет силу, удостоверение кейса 03 отозвано; `mandat attest-verify … --status-dir var/demo/status` показывает «отозвано».
5. `mandat monitor examples/events/takeover.json --status-dir var/demo/status` — тревога «возможный захват»: удостоверения организации приостановлены.
6. `mandat journal-proof var/demo/journal.jsonl --seq 3` — доказательство того, что решение есть в журнале, без раскрытия остальных записей.
