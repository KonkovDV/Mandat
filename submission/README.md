# Сдача

Что и когда сдаём на «Академии Финтеха 2026» (трек ВТБ «Финтех без границ: банк будущего для бизнеса и клиентов»). Главное: каждое число на слайде должно быть в [реестре утверждений](../CLAIMS_REGISTRY.md) и воспроизводиться командой.

Пакет для жюри: [README](../README.md), [сценарий показа](../docs/DEMO.md), [презентация](slides/Mandat_VTB.pdf), [пакет аналитики](analytics/README.md) (описание проекта, финансовая модель, оценка рынка, план внедрения и развития), [реестр утверждений](../CLAIMS_REGISTRY.md), [границы](../LIMITS.md).

## Этапы

Сроки — по сайту соревнования fintechacademy.ru (проверено 13.10.2026).

| Этап | Срок | Что сдаём | Где в репозитории |
|---|---|---|---|
| Заявка | до 11.10.2026 (в новостях о старте приёма — до 05.10.2026) | тексты полей, презентация | вне репозитория |
| Спринт 1 | до 01.11.2026 | вертикальный срез: 14 демо-кейсов, отчёт, журнал, удостоверение со статусом; итоги интервью; пакет аналитики по ссылке на облачный диск | `mandat demo`, `evidence.json`, `docs/discovery/`, `submission/analytics/` |
| Онлайн-питч | 10–15.11.2026 | 5 минут по [сценарию показа](../docs/DEMO.md) | `var/demo/*.html` |
| Спринт 2 | 16–29.11.2026 | доработка по обратной связи, профиль `strict`, обезличенные кейсы от эксперта | `docs/EVALUATION.md` |
| Спринт 3 | 03–08.12.2026 | план пилота, расчёт эффекта на данных интервью | `docs/PILOT.md`, `docs/ECONOMICS.md` |
| Финал | 11.12.2026, Финансовый университет, Москва | живое демо и ответы жюри | — |

Призовой фонд соревнования — 1,5 млн руб.: в каждом из двух треков три места, 350, 250 и 150 тыс. руб. (fintechacademy.ru). Лучшие команды могут пройти отбор в бизнес-инкубатор Финансового университета и пилотировать проект в ВТБ. Официальных критериев оценки трека в открытых источниках мы не нашли — их нужно запросить у организатора.

## Перед каждой сдачей

```bash
make check        # ruff, тесты, проверка формулировок
make evidence     # пересобрать evidence.json
mandat demo       # отчёты для показа
```
