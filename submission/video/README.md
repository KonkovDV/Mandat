# Видео-демо

Видео для поля заявки «Ссылка на развёрнутое демо или видео-демо его работы»: `out/Mandat_demo.mp4`, 1920×1080, около двух с половиной минут, субтитры на русском, без закадрового голоса.

Видео собирается из настоящего вывода продукта, а не из макета:

- карточки сотрудника — страницы `var/demo/*.html`, которые строит `mandat demo`;
- терминал — дословный вывод команд из `out/outputs.json`: `mandat demo`, `attest-verify`, `monitor` (отмена, захват и сроки МЧД), `journal-verify`, `journal-proof`, `mandat showcase` и запросы `curl` к поднятому `mandat serve`: разбор кейса и допуск платежа по OpenID AuthZEN 1.0. Для допуска кейс 14 копируется в `var/video` со сдвигом всех дат на одно число дней, чтобы день операции пришёлся на сегодня: сервер сверяет его с часами. По отчёту ядра выпускается удостоверение на одноразовый `nonce`, первый запрос получает «да», повтор того же — отказ с причиной. Пропуски обозначены «…», длинные хеши укорочены с «…», набор команды показан анимацией;
- числа качества и матрица готовности к пилоту — из `evidence.json` и `tests/test_redteam_fuzz.py`, как в колоде; данные Банка России — строки M-07, M-15 и M-52 [реестра утверждений](../../CLAIMS_REGISTRY.md).

## Сборка

Нужны установленный пакет (`make install` или `./run-demo.sh`), Node.js с Playwright и Chromium, ffmpeg с `libx264` и шрифт Golos Text из `submission/deck/fonts`.

```bash
python submission/video/capture.py      # прогоняет команды демо и API, пишет out/outputs.json
node submission/video/build_video.js    # кадры через Chromium, MP4 через ffmpeg
```

То же одной командой: `make video`.
