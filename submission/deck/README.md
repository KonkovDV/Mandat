# Презентация «Мандата» из кода

Как собрать презентацию, откуда на слайдах берутся числа и как устроено оформление. Технические числа (правила, тесты, корпус, интервалы, покрытие, задержка, мутации) подставляются из `evidence.json` и `tests/test_redteam_fuzz.py`, поэтому после пересборки совпадают с репозиторием без ручной правки.

Числа рынка и эффекта на слайдах 2, 3, 9, 10, 11 и в приложении — из открытых источников и допущений команды. Каждое из них записано в `CLAIMS_REGISTRY.md` вместе с источником или командой расчёта (`python scripts/effect_model.py --scenarios`). Параметры сценариев эффекта читаются из `src/mandat/data/effect_scenarios.json` — того же файла, что читает калькулятор.

## Сборка

Нужны Node.js 20+, Python 3.11+ и LibreOffice для выгрузки PDF. Для PDF установите шрифты из `fonts/` в систему (`~/.fonts` в Linux), иначе LibreOffice подставит другой шрифт.

```bash
cd submission/deck
npm ci                                   # первый раз; зависимости закреплены в package.json
node build_deck.js ../../evidence.json ../slides/Mandat_VTB.pptx
python finish_deck.py ../slides/Mandat_VTB.pptx
soffice --headless --convert-to pdf --outdir ../slides ../slides/Mandat_VTB.pptx
python finish_deck.py --pdf ../slides/Mandat_VTB.pdf
```

То же одной командой: `make deck`.

Колоду не нужно пересобирать в каждом PR: `scripts/lint_claims.py` допускает в ней число автотестов меньше
фактического из `evidence.json` (утверждение «N автотестов проходят» остаётся верным), но не больше и не 0.
Демо-кейсы и мутации фазза в колоде сверяются точно. Пересборка — к релизу или когда меняются другие числа.

`finish_deck.py` заменяет стандартную палитру на цвета из `theme.json`, ставит осмысленный alt-текст картинкам и признак «декоративный» значкам, записывает автором команду и проверяет файл: нет локальных путей в alt-тексте, нет цветов не в шестнадцатеричном виде, нет запрещённых формулировок из `BANNED_CLAIMS.txt`, нет имени программы-генератора в `docProps`. С `--pdf` то же для PDF.

## Оформление

Колода оформлена для трека ВТБ: палитра ВТБ, светлые слайды с белыми карточками, тёмно-синие обложка, разделы и финал.

| Роль | Цвет | Слот темы |
|---|---|---|
| Тёмно-синий ВТБ: заголовки, плашки выводов, фон обложки | `0A2973` | `dk2` |
| Кобальт: акценты, значки, ссылки | `004CBC` | `accent1` |
| Голубой ВТБ: графика на тёмном фоне | `00AAFF` | `accent2` |
| Текст | `0B1F44` | `dk1` |
| Фон контентных слайдов | `F3F6FB` | `lt2` |
| Вердикты: подтверждено, на разбор, опровергнуто, недостаточно данных | `1A9F68`, `F5A300`, `E5484D`, `6B7A99` | `accent3`–`accent6` |

Цвета ВТБ сверены по открытым источникам (Brandfetch, Trace Logo's, Encycolorpedia); официальный брендбук в открытом доступе мы не нашли. Голубой полос логотипа — `00AAFF`, тёмно-синий — `0A2973`. Логотип ВТБ в колоде не используется: колода — материал команды, а не банка.

**Шрифт.** Фирменный VTB Group UI (ParaType) в метаданных лицензирован «exclusive use by VTB Group (PJSC) only», поэтому команда его не использует и не распространяет. Вместо него — Golos Text от той же ParaType под SIL Open Font License: близкий гуманистический гротеск, по ширине строки отличается от VTB Group UI примерно на 3 %, а от Arial — меньше чем на 1 %. Если в PowerPoint шрифт не установлен, он подставит Arial, и вёрстка не поедет. Чтобы перейти на VTB Group UI (если банк выдаст лицензию), достаточно поменять `headFontFace` и `bodyFontFace` в `theme.json` и пересобрать.

**Графика** рисуется кодом в `graphics.js`: фон с сеткой связей, знак «Мандата» (изометрическая «М», как на логотипе проекта), иллюстрация «шесть источников — один вердикт на дату», значки Lucide в одном линейном стиле. Исходники SVG пишутся в `assets/svg/` при каждой сборке; их можно перетащить в Figma и править как вектор. Диаграммы, таблицы, схемы и плашки — родные объекты PowerPoint, их можно править без пересборки.

## Что где

| Файл | Содержимое |
|---|---|
| `build_deck.js` | 15 слайдов питча и 15 слайдов приложения с заметками докладчика, макеты «Обложка», «Контент», «Раздел», «Финал» |
| `graphics.js` | палитра, фоны, знак, иллюстрация графа полномочий, значки |
| `finish_deck.py` | тема, alt-текст, метаданные, проверки |
| `theme.json` | шрифт и палитра |
| `fonts/` | Golos Text (Regular, Medium, SemiBold, Bold) и лицензия OFL |
| `assets/` | фотографии команды `dmitrij.jpg`, `elena.jpg` (600×600); `svg/` — исходники графики для Figma |
