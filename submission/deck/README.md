# Презентация «Мандата» из кода

Как собрать презентацию и откуда на слайдах берутся числа. Технические числа (правила, тесты, корпус, интервалы, покрытие, задержка) подставляются из `evidence.json`, поэтому после пересборки совпадают с репозиторием без ручной правки.

Числа рынка и эффекта на слайдах 2, 9, 10 и в приложении — из открытых источников и допущений команды. Каждое из них записано в `CLAIMS_REGISTRY.md` вместе с источником или командой расчёта (`python scripts/effect_model.py --scenarios`). Параметры сценариев эффекта заданы в `build_deck.js` (объект `EFFECT`) и должны совпадать с калькулятором.

## Сборка

Нужны Node.js 20+, Python 3.11+ и LibreOffice для выгрузки PDF.

```bash
cd submission/deck
npm ci                                   # первый раз; зависимости закреплены в package.json
node build_deck.js ../../evidence.json ../slides/Mandat_VTB.pptx
python finish_deck.py ../slides/Mandat_VTB.pptx
soffice --headless --convert-to pdf --outdir ../slides ../slides/Mandat_VTB.pptx
python finish_deck.py --pdf ../slides/Mandat_VTB.pdf
```

То же одной командой: `make deck`.

`finish_deck.py` заменяет стандартную палитру на цвета из `theme.json`, ставит осмысленный alt-текст картинкам и признак «декоративный» значкам, записывает автором команду и проверяет файл: нет локальных путей в alt-тексте, нет цветов не в шестнадцатеричном виде, нет запрещённых формулировок из `BANNED_CLAIMS.txt`, нет имени программы-генератора в `docProps`. С `--pdf` то же для PDF: Creator и Producer — название проекта, имена генератора из XMP убраны. Если проверка не прошла, файл не меняется и команда завершается с ошибкой.
