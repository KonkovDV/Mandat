# Презентация «Мандата» из кода

Как собрать презентацию, откуда на слайдах берутся числа и как устроено оформление. Технические числа (правила, тесты, корпус, интервалы, покрытие, задержка, мутации) подставляются из `evidence.json` и `tests/test_redteam_fuzz.py`, поэтому после пересборки совпадают с репозиторием без ручной правки.

Числа рынка и эффекта на слайдах 2, 3, 4, 5, 15, 16, 17, 19, 21 и в приложении — из открытых источников и допущений команды. Каждое из них записано в `CLAIMS_REGISTRY.md` вместе с источником или командой расчёта (`python scripts/effect_model.py --scenarios`). Параметры сценариев эффекта читаются из `src/mandat/data/effect_scenarios.json` — того же файла, что читает калькулятор.

## Сборка

Нужны Node.js 20+, Python 3.11+, LibreOffice для выгрузки PDF и poppler (`pdftotext`, `pdffonts`, `pdftoppm`) с ImageMagick для проверки и картинок сайта. Для PDF установите шрифты из `fonts/` в систему (`~/.fonts` в Linux), иначе LibreOffice подставит другой шрифт.

```bash
cd submission/deck
npm ci                                   # первый раз; зависимости закреплены в package.json
node build_deck.js ../../evidence.json ../slides/Mandat_VTB.pptx
python finish_deck.py ../slides/Mandat_VTB.pptx
soffice --headless --convert-to pdf --outdir ../slides ../slides/Mandat_VTB.pptx
python finish_deck.py --pdf ../slides/Mandat_VTB.pdf
python qa_deck.py ../slides/Mandat_VTB.pdf               # проверка вёрстки, см. ниже
python export_slides.py ../slides/Mandat_VTB.pptx ../slides/Mandat_VTB.pdf   # слайды и текст выступления для сайта
```

То же одной командой: `make deck`.

`qa_deck.py` (перенесено из InvaRadar и расширено) читает PDF и PPTX и останавливает сборку, если на любом слайде: слова наезжают друг на друга; текст вышел за край слайда или за свою рамку (LibreOffice не сжимает лишнее, а рисует поверх соседей; рамки плейсхолдеров берутся из макета); слово разорвано между строками без дефиса («ДОКАЗАТЕЛЬСТ / ВА» — словарь берётся из самой колоды); последнее слово заголовка осталось на строке одно; в PDF попал шрифт не из `fonts/`.

`export_slides.py` выгружает слайды в WebP для сайта (`site/slides`) и пишет [SPEAKER_NOTES.md](SPEAKER_NOTES.md): текст выступления с хронометражем; темп выше 2,8 слова в секунду — ошибка.

Колоду не нужно пересобирать в каждом PR: `scripts/lint_claims.py` допускает в ней число автотестов меньше
фактического из `evidence.json` (утверждение «N автотестов проходят» остаётся верным), но не больше и не 0.
Демо-кейсы и мутации фазза в колоде сверяются точно. Пересборка — к релизу или когда меняются другие числа.

`finish_deck.py` заменяет стандартную палитру на цвета из `theme.json`, ставит осмысленный alt-текст картинкам и признак «декоративный» значкам, записывает автором команду и проверяет файл: нет локальных путей в alt-тексте, нет цветов не в шестнадцатеричном виде, нет запрещённых формулировок из `BANNED_CLAIMS.txt`, нет имени программы-генератора в `docProps`. Архив пишется без записей-каталогов: с ними часть облачных дисков не открывает файл. С `--pdf` то же для PDF.

Тесты в `tests/test_regressions.py` проверяют готовую колоду: осмысленный alt-текст, нет запрещённых формулировок и устаревших чисел, нет записей-каталогов, а каждый файл, который называют сноски слайдов и шаблоны пакета аналитики, есть в репозитории.

## Оформление

Колода оформлена для трека ВТБ: палитра ВТБ, светлые слайды с белыми карточками, тёмно-синие обложка, разделы и финал.

| Роль | Цвет | Слот темы |
|---|---|---|
| Тёмно-синий ВТБ: заголовки, плашки выводов, фон обложки | `0A2973` | `dk2` |
| Кобальт: акценты, значки, ссылки | `004CBC` | `accent1` |
| Голубой ВТБ: графика на тёмном фоне | `00AAFF` | `accent2` |
| Текст | `0B1F44` | `dk1` |
| Фон контентных слайдов | `F3F6FB` | `lt2` |
| Вердикты: подтверждено, на разбор, опровергнуто, недостаточно данных | `1A9F68`, `F5A300`, `E5484D`, `6B7A99` | `accent3`–`accent6` |

Цвета ВТБ сверены по открытым источникам (Brandfetch, Trace Logo's, Encycolorpedia); официальный брендбук в открытом доступе мы не нашли. Голубой полос логотипа — `00AAFF`, тёмно-синий — `0A2973`. Логотип ВТБ в колоде не используется: колода — материал команды, а не банка.

**Шрифты.** Фирменный VTB Group UI (ParaType) в метаданных лицензирован «exclusive use by VTB Group (PJSC) only», поэтому команда его не использует и не распространяет. Набор — три семейства под SIL Open Font License, все с полной кириллицей:

| Роль | Шрифт | Где |
|---|---|---|
| Заголовки слайдов, крупные числа, обложка | Manrope Bold и ExtraBold — геометрический гротеск с плотным рисунком | `headFontFace` в `theme.json`; весь жирный текст от 22 pt |
| Текст, таблицы, подписи, плашки вердиктов | Golos Text (ParaType) — гуманистический гротеск для экрана | `bodyFontFace` |
| Акцент обложки | Cormorant Garamond SemiBold Italic — курсив антиквы | одна строка на обложке |

Пара «геометрический гротеск в заголовках и гуманистический в тексте» даёт заголовкам характер, а длинный текст оставляет читаемым; курсив антиквы — один акцент, а не второй голос. Если в PowerPoint шрифты не установлены, он подставит системные, и строки могут сдвинуться: показывайте PDF, в нём шрифты встроены. Чтобы перейти на VTB Group UI (если банк выдаст лицензию), достаточно поменять `headFontFace` и `bodyFontFace` в `theme.json` и пересобрать: `qa_deck.py` покажет, где поменялись переносы.

**Графика** рисуется кодом в `graphics.js`: знак «Мандата» (изометрическая «М», как на логотипе проекта), окно терминала, значки Lucide в одном линейном стиле, а также запасной фон с сеткой связей и иллюстрация «шесть источников — один вердикт на дату». Исходники SVG пишутся в `assets/svg/` при каждой сборке; их можно перетащить в Figma и править как вектор. Диаграммы, таблицы, схемы и плашки — родные объекты PowerPoint, их можно править без пересборки.

**Изображения из Figma** (`assets/visuals/`, правила образа — [docs/VISUALS.md](../../docs/VISUALS.md)): фон тёмных слайдов с атласными волнами и золотыми нитями; Анна, амбассадор «Мандата», на обложке, слайде 19 и финале; 3D-значки на слайдах 2 и 22. Фото на тёмном слайде ложится на тот же кусок фона, что у макета, и слева уходит в него без шва (`photoPanel` в `graphics.js`). Файлы из Figma переводятся в JPEG для колоды и WebP для сайта командой `python import_visuals.py ПАПКА`.

**Фото команды** на слайде 22 — два круга: квадрат по лицу вырезается из исходного кадра при сборке (`squarePhoto`), неоновая рамка исходника в круг не попадает.

## Типографика, доступность, навигация

- **Русская типографика** — функция `typo()` в `build_deck.js`: неразрывный пробел после коротких слов, перед тире, между числом и единицей, в «ст. 188», «№ 1001», инициалах; неразрывный дефис в «243‑ФЗ», «ОД‑2506», «стоп‑критерий». Пути, команды и латинские коды не трогаются, их можно копировать. `lint_claims.py` и `finish_deck.py` перед проверками заменяют неразрывные знаки обычными, поэтому типографика не прячет числа и запрещённые формулировки.
- **Доступность (WCAG 2.2 AA)** — контраст всех пар «текст — фон» не ниже 4,5:1 (крупного — 3:1); вердикт всегда подписан словом и значком, а не только цветом; у картинок alt-текст, значки помечены декоративными; язык текста — `ru-RU` (ставит `finish_deck.py`).
- **Навигация** — слайд 2 ведёт на подробные слайды, оглавление приложения (слайд 24) — на каждый слайд A1–A18, каждый слайд приложения — обратно к оглавлению. Ссылки сделаны прозрачными зонами поверх текста: PowerPoint не перекрашивает такой текст в цвет гиперссылки темы. Номера слайдов в оглавлении считаются при сборке, расхождение останавливает сборку.

## Настоящие данные демо

Слайды 9, 10 и 11 показывают настоящий вывод продукта, а не макет:

- скриншот карточки кейса 14 — `assets/demo-card-14.jpg`, верх карточки крупно (окно 920 пикселей, текст на слайде около 7–8 пунктов); переснять: `./run-demo.sh` в корне, затем `node capture_demo.js` (нужен Playwright с Chromium);
- вывод терминала — константа `TERMINAL` в `build_deck.js`, строки взяты из `mandat demo`, `mandat attest-verify` и `mandat monitor examples/events/takeover.json` (сценарий — `docs/DEMO.md`); пропущенные строки обозначены «…»;
- ось времени слайда 6 строится из файлов демо-кейса 14 (`egrul.json`, `poa-root.xml`, `case.json`) при каждой сборке;
- «Шесть экранов» на слайде 10 — та же картинка, что на главной сайта (`site/img/devices-2400.webp`): `device_art.js` снимает настоящие страницы собранного сайта; на слайде прозрачный фон залит цветом фона слайда. После правки страниц сайта картинку пересобирают по [docs/VISUALS.md](../../docs/VISUALS.md#цепочка-и-шесть-экранов), затем `make deck`;
- шаги слайда 11 — отчёт `mandat showcase` (`var/showcase/showcase.json`): название шага, итог и причина дословно, причина, которая не помещается, сокращается с «…». `make deck` запускает сценарий перед сборкой, а сборка останавливается, если шаги или журнал сценария не те, на которые рассчитан слайд.

На слайде 10 — QR-код сайта, на финальном — два QR-кода: `assets/qr-site.svg` ведёт на сайт с демо в браузере (`https://konkovdv.github.io/Mandat/`), `assets/qr-github.svg` — на `https://github.com/KonkovDV/Mandat`; оба проверены распознаванием с отрисованного слайда.

## Порядок сборки

Слайды 2, 15 и приложение берут окупаемость и отдачу для ВТБ из пересчитанной финансовой модели (`submission/analytics/out/model_values.json`). Поэтому порядок такой: `python submission/analytics/build_model.py` → `make deck` → `python submission/analytics/build_docs.py --package …`. Если ставки или ущерб модели расходятся с `effect_scenarios.json`, сборка колоды останавливается с подсказкой пересобрать модель.
