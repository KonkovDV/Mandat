# Форма сдачи Спринта 1: тексты полей

Готовые тексты для формы «Итоговая работа команды для оценки жюри» (Академия Финтеха 2026, трек ВТБ). Числа сверены с `evidence.json` от 28.10.2026 и [реестром утверждений](../CLAIMS_REGISTRY.md). Если в поле есть ограничение по длине, берите короткий вариант.

## Над какой задачей вы работаете?

Финтех без границ: банк будущего для бизнеса и клиентов

## Название проекта

Мандат

## Краткое описание проекта

**Короткий вариант** (≈250 знаков):

> «Мандат» отвечает банку, вправе ли представитель провести операцию от имени компании в этот день, и доказывает ответ полем МЧД, записью ЕГРЮЛ и нормой закона. Неизвестное никогда не становится «да». Работает в контуре банка.

**Полный вариант** (≈600 знаков):

> «Мандат» — движок проверки полномочий представителей бизнеса для банка. На вопрос «вправе ли X провести операцию O от имени компании Y на дату t» он даёт один из четырёх ответов — подтверждено, опровергнуто, на разбор, недостаточно данных — с доказательством до поля МЧД, записи ЕГРЮЛ и статьи закона. 39 правил сводят МЧД, ЕГРЮЛ, устав и реестр на дату операции; неизвестное никогда не становится «да». После выдачи прав «Мандат» следит за сменой директора и отменой доверенностей и приостанавливает удостоверения при признаках захвата компании — до платежа. Работает в контуре банка, без внешней сети.

## Ключевые результаты спринта

**Полный вариант** (≈1500 знаков):

> 1. Вертикальный срез работает одной командой (./run-demo.sh): 14 демо-кейсов дают все четыре вердикта, карточка сотрудника с нормой и следующим шагом, журнал решений с деревом Меркла, удостоверения со статусом «действует / приостановлено / отозвано», мониторинг захвата компании, HTTP API с ролями.
> 2. Качество на корпусе из 294 кейсов 49 видов: 0 ложных «подтверждено» из 288 (верхняя граница 95 % — 1,3 %), 8814 мутаций без ложного «да» и без падений, 384 цепочки передоверия совпали с независимой реализацией на Cedar; 1600 автотестов проходят, покрытие кода 95,7 %, медиана проверки ≈3 мс.
> 3. Сверка с внешними эталонами: каноническая запись RFC 8785, дерево Меркла RFC 6962, подпись по векторам W3C eddsa-jcs-2022.
> 4. Пакет аналитики: описание проекта, финансовая модель на формулах (три сценария, 0 ошибок), оценка рынка TAM/SAM/SOM двумя способами, план внедрения с воротами и RACI. Эффект для ВТБ в базовом сценарии — 75 ставок и 140 млн ₽ предотвращённого ущерба в год, окупаемость разовых затрат — 7,5 месяца.
> 5. Презентация (19 слайдов питча и 19 приложения) на данных Банка России за I полугодие 2026 года, с реальными кейсами («ЭОС», 10.2026; ВС РФ № 308-ЭС22-17199) и мировой практикой (FATF R10, AMLR ЕС, Companies House, KvK и Signicat, бизнес-кошелёк ЕС, мандаты ИИ-агентов AP2); видео-демо на настоящем выводе продукта.
> 6. Фактчекинг каждого числа, Red Team и Murder Board всех материалов; запрос к ВТБ — шестинедельный теневой пилот на праве подписи платёжных поручений по МЧД.

**Короткий вариант** (≈470 знаков):

> Работающий срез: 14 демо-кейсов, четыре вердикта с нормой и полем документа, журнал Меркла, удостоверения со статусом, мониторинг захвата, HTTP API. Качество: 0 ложных «подтверждено» из 288 (граница 1,3 %), 8814 мутаций без сбоя, 1600 автотестов. Пакет аналитики: финмодель на формулах (3 сценария), рынок TAM/SAM/SOM, план пилота; эффект для ВТБ — 75 ставок и 140 млн ₽ в год, окупаемость 7,5 месяца. Презентация на данных Банка России 2026 и реальных кейсах, видео-демо.

## Как загрузить на Яндекс Диск

1. Соберите папку: `make submission` (или возьмите готовый архив `Мандат_пакет_аналитики_28.10.2026.zip` и распакуйте его).
2. На disk.yandex.ru: «Загрузить» → выберите папку `Мандат_пакет_аналитики_28.10.2026` целиком.
3. Папка → «Поделиться» → «Скопировать ссылку»; доступ — «Просмотр для всех, у кого есть ссылка». Это ссылка для поля «артефакты аналитики».
4. Так же откройте доступ к файлам `05_Презентация_Мандат_ВТБ.pdf` и `06_Видео-демо_Мандат.mp4` по отдельности и вставьте их ссылки в поля презентации и видео.
5. Проверьте каждую ссылку в окне браузера без входа в аккаунт (режим инкогнито): файл должен открываться без запроса доступа.

В Облаке Mail (cloud.mail.ru) порядок тот же: «Загрузить» → «Поделиться ссылкой» → «Доступ по ссылке».
