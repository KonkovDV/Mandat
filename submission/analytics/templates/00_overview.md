# Что в пакете и как его читать

::: lead
«Мандат» отвечает, вправе ли человек провести операцию от имени компании в этот день, и доказывает ответ полем документа, записью ЕГРЮЛ и нормой; неизвестное никогда не становится «да». В пакете — всё, что просит поле заявки: описание проекта, финансовая модель, оценка рынка, план внедрения и развития. Всё, что работает, проверяется командой из репозитория; параметры, которые зависят от данных банка, калибруются в шестинедельном теневом пилоте.
:::

::: main
Главное

- **Задача банка** — за секунды решить, вправе ли представитель действовать за компанию, и доказать решение. Ошибка дорогая: в I полугодии 2026 года у юрлиц — [[ n(cbr.h1_ops, 0) ]] операций без согласия на [[ n(cbr.h1_loss / 1000, 1) ]] млрд ₽; во II квартале средняя операция — [[ n(cbr.q2_avg, 2) ]] млн ₽, в [[ cbr.q2_ratio ]] раз крупнее средней, а компаниям возмещено меньше пятой части.
- **Продукт работает:** [[ cp(ev.rules, "правил") ]] с нормой и тестом, ноль ложных «подтверждено» на [[ ev.negatives ]] кейсах-ловушках, [[ cp(ev.tests, "автотест") ]], медиана проверки — [[ n(ev.median_ms, 1) ]] мс, демо одной командой.
- **Для ВТБ** в базовом сценарии — [[ n(b.fte_round[1], 0) ]] ставок и [[ n(b.prevented_round[1], 0) ]] млн ₽ предотвращённого ущерба клиентов в год; разовые затраты банка окупаются за [[ months(b.payback_cash[1]) ]], чистая отдача — [[ n(b.roi_cash[1]) ]] ₽ на рубль затрат за три года.
- **Рынок:** ценность задачи для банков России — [[ bln(mk.pool_bank[1]) ]] млрд ₽ в год, вместе с ущербом их клиентов — [[ bln(mk.pool_social[1]) ]] млрд ₽; выручка поставщика при полном охвате операций (TAM) — [[ bln(mk.tam_full[1]) ]] млрд ₽ в год. К 2031 году — [[ cp(base.c.banks_2031, "банк") ]] и [[ n(base.c.revenue_2031, 1) ]] млн ₽ выручки. Дальше — сервис для бизнес-клиентов и мандаты для ИИ-агентов.
- **Проекту нужно** [[ n(base.c.funding, 0) ]] млн ₽ до выхода на операционную прибыль в [[ yr(base.c.year_ebitda) ]] году. Ближайший шаг — шесть недель теневого пилота в ВТБ.
:::

# Как проверить числа

Числа о продукте подставляются в документы из `evidence.json`, эффект для ВТБ — из того же файла параметров, что читают калькулятор и презентация, рынок и финансы — из пересчитанной модели. Руками числа не набираются. Каждое утверждение и его граница — в реестре утверждений `CLAIMS_REGISTRY.md`.

```
git clone https://github.com/KonkovDV/Mandat && cd Mandat
make check                                    # линтеры, [[ cp(ev.tests, "автотест") ]], проверка формулировок
mandat demo                                   # [[ cp(ev.demo, "демо-кейс") ]]: отчёты, журнал, удостоверения
mandat eval --per-defect 6                    # корпус: [[ cp(ev.cases, "кейс") ]], [[ ev.kinds ]] видов
python scripts/effect_model.py --scenarios    # ставки и ущерб для ВТБ
python submission/analytics/build_model.py    # финансовая модель: пересчёт и проверки
python submission/analytics/build_docs.py     # эти документы из шаблонов и модели
```

# Как читать числа

| Метка | Что значит |
|------------------|------------------------------------------------------------|
| [[ tag("репозиторий") ]] | воспроизводится командой из репозитория; условия — в реестре утверждений |
| [[ tag("факт") ]] | взято из первоисточника: Банк России, ФНС, текст закона |
| [[ tag("вторичный") ]] | число из обзора или СМИ со ссылкой на первоисточник |
| [[ tag("допущение") ]] | параметр сценария с обоснованием; пилот калибрует его на данных банка |
| [[ tag("гипотеза") ]] | проверяется продажами или переговорами: цена, сроки договоров |

Числа о качестве получены на корпусе из [[ cp(ev.cases, "кейс") ]] [[ ev.kinds ]] видов, сгенерированных по нормам ГК РФ и формату МЧД: это проверка логики правил на всех известных видах дефектов. На документах ВТБ те же метрики измеряет теневой пилот, а правила утверждает юрист банка в первую неделю.

# Запрос к ВТБ

::: conclusion
**Шестинедельный теневой пилот через Акселератор ВТБ** на одной операции — праве подписи платёжных поручений по МЧД. «Мандат» проверяет те же пакеты, что и сотрудники, на выдачу прав не влияет; пилот останавливается при первом ложном «подтверждено». От банка: владелец процесса, регламент операции, 50–100 обезличенных пакетов или тестовый контур, юрист для утверждения правил.
:::
