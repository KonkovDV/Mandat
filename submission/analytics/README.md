# Пакет аналитики

Артефакты для поля заявки «Ссылка на облачный диск с артефактами аналитики: описанием проекта, финансовой моделью, оценкой рынка, планом внедрения и развития». Бриф, по которому собран пакет, — [PROMPT.md](PROMPT.md). Главное правило: числа в документах не набираются руками — о продукте они берутся из `evidence.json`, эффект для ВТБ — из `src/mandat/data/effect_scenarios.json`, рынок и финансы — из пересчитанной финансовой модели.

## Сборка

Нужны Python 3.11+ с `openpyxl`, `jinja2`, `pypdf`, `fontTools`; LibreOffice (пересчёт формул); pandoc 3; Node.js с Playwright и Chromium (печать PDF). Шрифт Golos Text берётся из `submission/deck/fonts`.

```bash
python submission/analytics/build_model.py              # модель: формулы, пересчёт LibreOffice, проверки
python submission/analytics/build_docs.py               # документы PDF из шаблонов и модели
python submission/analytics/build_docs.py --package ..  # ещё и папка с русскими именами и архив для диска
```

То же одной командой: `make analytics`. Колода берёт окупаемость для ВТБ из пересчитанной модели, поэтому полный порядок такой: модель → `make deck` → документы и папка для диска; всё вместе с видео — `make submission`.

## Как устроено

- `data/inputs.json` — все допущения модели и оценки рынка: значения по трём сценариям, тип (факт, вторичный источник, допущение, гипотеза), источник и способ проверки на пилоте; список источников S01–S30.
- `build_model.py` пишет книгу Excel по принципам FAST: допущения отделены от расчётов, в строке одна формула для всех лет, три сценария на листах одной структуры, «торнадо» — блоками той же структуры. Книгу пересчитывает LibreOffice; лист «Проверки» сверяет ставки и ущерб с реестром утверждений (C-15, C-16) и целостность расчёта. Значения после пересчёта уходят в `out/model_values.json`.
- `templates/*.md` — тексты документов (Markdown для pandoc, Jinja2 с разделителями `[[ ]]` и `[% %]`). `build_docs.py` подставляет числа, собирает HTML, расставляет неразрывные пробелы и дефисы теми же правилами, что колода, и печатает PDF через `render_pdf.js`.
- `charts.py` рисует графики и схемы в SVG: палитра колоды, Golos Text, подписи данных выборочно, сценарии — порядковая шкала одного тона. Ширина подписей считается по метрикам шрифта.
- `style.css` — оформление A4: обложка, колонтитулы, плитки чисел, таблицы, метки статуса чисел.

## Проверки при сборке

- Модель: ноль ошибок в формулах после пересчёта, все строки целостности на листе «Проверки» — «ОК».
- Тексты: запрещённые формулировки из `BANNED_CLAIMS.txt`, число правил, автотестов, демо-кейсов и мутаций, согласование числа и слова — функциями `scripts/lint_claims.py`; любая ошибка останавливает сборку.
- PDF: только Golos Text и моноширинный шрифт кода, теговая структура, закладки по заголовкам, язык `ru-RU`, автор — команда, без имени программы-генератора.

Новые рыночные и правовые факты пакета записаны в [реестр утверждений](../../CLAIMS_REGISTRY.md) строками M-20–M-42 вместе с границей каждого; база ущерба — данные Банка России за I полугодие 2026 года (M-07, M-15).
