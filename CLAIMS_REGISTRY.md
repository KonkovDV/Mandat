# Реестр утверждений

Каждое число и каждое сильное утверждение в презентации, заявке и на питче должно быть здесь — с командой, которая его воспроизводит, и границей, за которую оно не выходит. На питче называйте номер строки. Формулировки из `BANNED_CLAIMS.txt` не используем нигде, кроме этого файла. Текст презентации (слайды и заметки `Mandat_VTB.pptx`) проверяется той же командой `python scripts/lint_claims.py`. Ревизия от 12.10.2026. Как проговорить это в зале — [docs/DEMO.md](docs/DEMO.md).

| C-04 | Все виды опровергающих дефектов распознаны, нижняя граница 95% полноты ≈ 0,966 (108 опровергающих кейсов) | то же | то же |

## Как нельзя и как можно

| Нельзя | Можно |
|---|---|
| «ИИ принимает решение», «ИИ определяет полномочия», «модель выносит вердикт» | «правила выносят вердикт, модель подсказывает факты с цитатой, спорное решает сотрудник» |
| «юридически значимая проверка» | «доказательная поддержка решения сотрудника банка» |
| «права выдаются автоматически», «автоматически отзывает права» | «рекомендует роль; при событии запускает перепроверку и меняет статус удостоверения» |
| «проверка КЭП выполнена», «проверяем КЭП по ГОСТ» | «порт проверки КЭП готов к подключению СКЗИ банка» |
| «интегрирован с реестром ФНС», «коды классификатора Минцифры» (про текущий стенд) | «порт реестра готов, в стенде — заглушка»; «коды синтетические, импорт из ЕСНСИ готов» |
| «смена директора аннулирует доверенности» | «смена директора доверенность не прекращает; свежая смена — повод для разбора» |
| «соответствует 152-ФЗ», «соответствует ГОСТ Р 57580», «соответствует приказу ФСТЭК» | «спроектировано с учётом 152-ФЗ: on-prem, псевдонимизация, минимизация» |
| «гарантируем отсутствие мошенничества» | «снижаем риск захвата и действий по оборванной цепочке» |
| «точность 99%», «100% точность» | цифры C-03…C-06 с границей |
| «внедрено в ВТБ», «одобрено ВТБ» | «готовы к пилоту на обезличенных кейсах» |
| «ВТБ не умеет», «никто на рынке не умеет» | «в открытых источниках не нашли продукта, который сводит МЧД, ЕГРЮЛ и устав в один вердикт на дату с доказательствами» |
